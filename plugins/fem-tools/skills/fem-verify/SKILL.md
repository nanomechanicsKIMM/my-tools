# fem-verify — FEM 검증표 자동 생성 (FEniCSx 전용)

유한요소해석 결과를 신뢰하기 전 7항목 검증 체크리스트를 표준 검증표로 코드화한다.
**구현과 분리된 lane**에서 동작한다(self-approve 금지). 깊은 검증은 `fem-verifier` 에이전트로 위임.
**임의의 FEM 문제**에 적용된다.

## 사용 시점
- 해석 결과(`results/<단계>`)를 신뢰하기 전 2~3개 독립 증거를 수집할 때.
- **FEniCSx/dolfinx 해석 검증에만 사용한다.** 일반 소프트웨어 테스트가 아니다.

## 절차
1. 검증 대상 양(예: 응력·변위·곡률·반력·전달률·접촉압)과 가능한 검증 채널을 식별.
2. 아래 7항목 중 **2~3개**를 선택해 증거를 수집(`references/analytic_solutions.md` 참조).
3. `templates/verification_table.md`로 검증표를 채운다.
4. 미수렴·미달·정정은 fail loud로 표기.

## 7항목 검증 채널
| # | 채널 | 대표 기준(예시) |
|---|---|---|
| 1 | 해석해 비교 | 캔틸레버 처짐, Lamé 원통, Kirsch $K_t{=}3$, Kirchhoff/Hencky 평판, Stoney, shear-lag $I_0(R/λ)$ |
| 2 | MMS | 해 가정→소스 역산→수렴률 $O(h^{k+1})$ |
| 3 | 메쉬 수렴 | 2~3 해상도 관심량 안정 |
| 4 | 극한 케이스 | 파라미터 극단에서 알려진 극한 |
| 5 | 단조·대칭·보존 | 평형/반력 균형, 단조성, 질량·에너지·체적 |
| 6 | 교차검증 | 독립 정식화로 동일 결론 |
| 7 | 수렴 품질 | Newton ≤~6, (접촉) 침투≪두께 |

## 합격 기준 (가이드)
- 해석해 일치 오차는 문제의 적용범위 내에서 통상 ≤ 수 % (벤치마크에 따라 다름).
- 메쉬 수렴 자체 오차는 모델링 편차보다 충분히 작아야 함.
- 보존/평형 잔차는 수치 허용오차 수준.

## 골격 상태
- `references/analytic_solutions.md` — 일반 FEA 해석해/벤치마크 인덱스(채워짐).
- `templates/verification_table.md` — 검증표 템플릿(채워짐).
- Python 자동화(해석해 라이브러리·수렴률 계산)는 **다음 실해석에서 점진 추출**(현재 stub 없음). 그때까지는 표 템플릿+공식 인덱스로 수동 작성.
