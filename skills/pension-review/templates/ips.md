# 투자정책서 (Investment Policy Statement)

> [!info] 기계판독 정책 `status/ips_policy.json` 과 쌍으로 유지하고, `scripts/ips_check.py`로 분기 자동 대조한다.
> 수치는 반드시 검증층(부트스트랩·walk-forward·라이프사이클) 실증 결과로 채운다. 투자 권유 아님.

## 1. 목표
- 출생연도 · 은퇴 시점 · 인출 기간 · 계좌유형. 성공 지표 = **고갈확률 ≤ N%** (실질 월지출 기준, lifecycle_sim 산출).
- 안전인출 기준점: 실질 월 ___만원 (기반·시점 명기, 분기 갱신).

## 2. 전략배분
- 위험 __% / 안전 __% + 근거(연령 규칙·glidepath 채택 여부는 lifecycle_sim으로 검증 후 결정).
- 목표배분 파일: `status/targets_*.json` · 밴드 ±_%p.

## 3. 리밸런싱 정책
- 방식(현금흐름/밴드/캘린더) + rebalance_policy.py 실증 근거(고갈확률·회전율).

## 4. 환헤지 정책
- H/UH/동적 + fx_overlay.py 실측 근거(CAGR·위기 MDD).

## 5. 한도 (ips_check.py 자동 판정)
| 항목 | 한도 |
|---|---|
| 위험자산 | ≤ 70% (법정) |
| 단일펀드 | ≤ 40% (법정) |
| 목표배분 밴드 | ±_%p |
| 펀드 수 | _~_개 |
| 가중 TER(총자산) | ≤ _.__% |
| 신흥국 합계 | ≤ _% |

## 6. 금지행동
> [!danger]
> 1. 급락 시 리밸런싱 외 매도 금지. 2. 신규 수익 알고리즘 탐색 금지(음성 확정 시). 3. 집중 한도 위반 금지.
> 4. 검증층 미통과 상품 편입 금지. 5. SoT 외 수치 의사결정 금지.

## 7. 리뷰 주기·트리거
- 분기 run_quarterly.py + 수시 트리거(급변·펀드 변경·목표 변경).
