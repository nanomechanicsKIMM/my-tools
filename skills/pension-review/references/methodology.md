# pension-review 방법론

## 1. 데이터 — KOFIA 일별 NAV
- 출처: dis.kofia.or.kr proframeWeb XMLSERVICES(COMFundPriceModSO.priceModSrch), 표준코드 무인증.
- 일별 요청당 ~120영업일 캡 → `to` 이동 페이지네이션으로 5년치 수집.
- 응답 필드: standardDt(기준일), standardCot(기준가), standardassStdCot(과표기준가), kospi/kospi200/kosdaq 지수.
- **분배금 필드 없음** → 분배락은 기준가 패턴으로 추정(아래).

## 2. 분배락 보정 (수정기준가)
- 한국 펀드는 결산 시 분배 후 기준가를 ~1000으로 리셋 → 원기준가에 가짜 폭락.
- 탐지 규칙: `|nav − 1000| ≤ 1.5 AND nav[d−1]/nav[d] ≥ 1.003`.
- 보정: 분배락일 계수(nav[d]/nav[d−1])를 이전 전구간에 누적 곱(후방조정) → 일일수익률 보존.
- **한계(검증됨)**: tax_nav·시장지수·factor 가드 모두 분배/시장변동 구분 불가. 정탐/과탐이 모든 factor 범위에 혼재. 1000 외 리셋 펀드(리츠 등)는 미탐지. **기준가 데이터만으로 완전 해결 불가** → KOFIA 분배내역 API가 유일 근본해법. 단 일일수익률 기반 백테스트엔 영향 제한적.

## 3. 패널 — NaN 정책
- 날짜×코드 wide 패널, 결측 ffill **금지**.
- 결측 의미: 자격밖(설정전/데이터끝후)·내부공백(휴면)·산발누락.
- 효과: **룩어헤드·생존편향 암묵 차단**(미설정 펀드 자동 후보 제외). lag0≈lag1로 검증.

## 4. 백테스트 엔진 — forward-pricing
- 신호는 T일 종가 NAV까지, 체결은 T+execution_lag NAV → 룩어헤드 차단.
- TER 재차감 금지(NAV에 이미 반영). cost_bps는 펀드 교체 거래비용만.
- 보유 중 NaN(휴면)은 직전가 동결 평가(navff).
- **경량엔진(mc_backtest.fast_run)**: 리밸 구간 벡터화. 신생펀드 0×NaN 전파를 `nan_to_num`으로 차단(전체 283 NaN 패널 필수).

## 5. DC 규제 제약
- 위험자산 ≤70%, 단일펀드 ≤40%. 잔여=현금(또는 예금).
- code→riskAsset 매핑: `_metadata.json` name → `fund_classification.json`.
- 적용 순서: 단일캡 → 위험합 비례축소 → 잔여 현금. 위험조정성과(Sharpe·MDD) 개선 효과.

## 6. 다중경로 — Stationary Block Bootstrap
- 일별 수익률을 가변 블록(평균 L=40일)으로 리샘플 → N개 합성 경로.
- 변동성 군집·횡단 상관 보존, 시간 순서 제거 → **강세장 편향 제거**.
- 하위 경로(CAGR 하위25%) = 하락장 시나리오. Sharpe 1위 빈도·분포로 강건성 평가.
- 핵심 결과: 추천 고정비중이 단일·다중경로 모두 우위(예금쿠션·저회전·추정오차 면역).

## 7. 슬롯 기반 추천 (5단계)
- ① 안전게이트 ② 연령 위험비중 ③ 핵심-위성 슬롯 ④ 슬롯별 랭킹(최저보수/최대순자산) ⑤ 컴플라이언스.
- 추천 6/6 재현 검증. 시점별 동적 선택 → proxy 문제 자연해결, 고정 추천 능가(Sharpe 1.409 vs 1.352).
- 비중(22/13/15/8/7/35)은 최적화 아닌 하향식 규칙 휴리스틱(연령·한도·코어우위).

## 8. 글로벌 분산
- 상관매트릭스: 미국 3자산 고상관(0.77~0.80=1베팅), 한국 KOSPI-가치 0.94 중복, 중국·인도 저/음상관(진짜 분산재).
- 신흥국: 인도(고수익+저상관, Sharpe 0.95) > 중국(분산되나 수익 약).
- **정량+정성 교차검증 필수**: 백테스트 일별상관(인도 0.26)은 실제 장기상관(0.62)을 과소평가 → `/deep-research`로 고평가·환율·상관 보정. 신흥국 ≤8%, 환헤지·DCA.

## 9. 알려진 한계
- 분배락 탐지 휴리스틱(1년+ ±수%p 오차).
- 생존편향: 현재 가입가능 펀드만 수집(과거 청산 펀드 부재).
- proxy 펀드(신생 미국펀드는 동적 슬롯 선택으로 완화).
- 과거 강세 편향(부트스트랩도 원본 분포 기반).
- 신흥국 분산효과 일별 백테스트 과대평가 가능.

## 10. 신규 알고리즘 엄밀 평가 (3-에이전트 + 페어 부트스트랩 심판)
- **심판 `algo_eval.evaluate`**: 동일 부트스트랩 경로에서 추천65/35와 후보를 **페어** 백테스트 → 중앙·5/95p·페어승률. 게이트 = 후보 CAGR ≥ 1.10×추천 AND |MDD| ≤ 0.90×추천. seed 고정 재현.
- **3-에이전트 분리**: ①도출(GitHub 퀀트레포 조사→스펙) ②백테스트(구현+evaluate) ③비평(독립 적대 감사). 비평 출력은 **파일로** 받아 캡처 누락 회피.
- **과적합 가드(필수, 거짓양성 방어)**:
  1. **사후편향(hindsight pool)** — Stationary Block Bootstrap은 시간순서만 섞고 **각 펀드 실현수익은 보존**. 풀을 "실현수익 양(+)" 기준으로 큐레이션하면 그 수익이 합성경로에 baked-in → CAGR 우위 위조. **검증**: 승자 상위2종 제거 + 수익무관 ex-ante(AUM/카테고리, 주식형만) 풀 재평가. (실증: 후보 CAGR배수 1.124→1.022→0.48로 붕괴, MDD 우위만 생존)
  2. **비동기 NAV 상관 아티팩트** — 아시아펀드 NAV는 미국과 다른 세션 체결 → 동일달력일 對S&P 상관(0.13~0.26)이 진짜 경제연동 과소평가 → 부트스트랩이 공동하락(MDD) 과소반영 → MDD 개선 0.5~1%p 과대. 시차상관(asia_t+1 vs sp_t)으로 점검.
  3. **데이터 스누핑** — 다변형·다시드 반복 = 다중검정. 음성 결론 후 추가 탐색은 거짓양성 생성. 홀드아웃 다중시드 교차검증 의무.
- **결론(검증됨)**: 분산 inverse-vol 리스크버짓은 **MDD/Sharpe만 강건 개선**(수익무관 구조효과), **+10% CAGR은 사후 승자선택 없이 불가**(무차익). 추천65/35는 표본외 효율적 벤치마크. 개선 여지는 "분산으로 MDD↓"이며 walk-forward OOS 검증 필요.
- TradingAgents(LLM 멀티에이전트)는 퀀트 라이브러리 아님 → NAV 시그널로 변환 가능한 것만 추출(MACD·200SMA·RSI·변동성타게팅). 단 부트스트랩이 추세형 타이밍에 불리해 대부분 고정비중에 패배.

## 12. Walk-Forward 표본외(OOS) 검증 (`walkforward_oos.py`)
- **동기**: 부트스트랩(§6)은 시간순서만 섞고 분포는 보존 → *알고리즘/하이퍼파라미터 선택*의 과적합(데이터 스누핑)은 못 잡음. walk-forward는 그 선택을 **과거 데이터로만** 하고 다음 구간(표본외)에서 검증.
- **용어**: algos=배분 알고리즘(검증 대상) · OOS=학습에 안 쓴 다음 구간 성과 · walk-forward=학습창을 미래로 전진시키며 매 fold 검증.
- **설계(검증된 엔진 재사용, skfolio 미사용)**: skfolio는 고정유니버스·clean matrix 전제라 DC제약·예금쿠션·forward-pricing·동적 eligibility를 빠뜨려 기존 Phase 5와 수치 비교 불가 → `mc_backtest.fast_run` 재사용으로 일관성 확보. skfolio는 고정유니버스 독립 교차검증용으로 보류.
  - 유니버스 = `algo_eval._universe`(full_5y 생존 + 추천 proxy, dropna).
  - fold = anchored(expanding) 학습 `[0,t)` → OOS 테스트 `[t,t+TEST)`, STEP씩 전진(비중첩). 기본 TEST=STEP=126(6mo), FREQ=QE, 학습오프셋 WARMUP+MIN_TRAIN=504.
  - 매 fold: 후보 10종(DC래핑)을 학습구간 Sharpe로 채점→승자→테스트 적용. WF-Select/추천65/35/개별algo고정/동일가중을 **동일 fold 경계로 stitch**. algo 전환 fold엔 전환비용(0.2%) 차감(낙관편향 방지).
  - 게이트 = `algo_eval`과 동일(WF-Select OOS CAGR ≥ 1.10×추천 AND |MDD| ≤ 0.90×추천).
- **실증(2021-06~2026-06, 236펀드, 6 fold)**: WF-Select OOS **CAGR 26.2 / Sharpe 1.81 / MDD −12.2%** vs 추천65/35 **CAGR 23.9 / Sharpe 2.45 / MDD −6.7%**. 게이트 **FAIL**(CAGR·MDD 모두 미달, fold승률 3/6). fold 4에서 선택(평균-CVaR)이 OOS CAGR 1.9%로 추천 22.3%에 붕괴 — *과거 최선 algo 선택이 표본외에서 무너지는* 전형적 과적합. **결론: 고정 추천65/35의 표본외 우위 재확인.**
- **한계**: 5년 일별 → fold 6개로 통계력 낮음(넓은 오차). 직교 보강책 = FDR 장기 실지수(KS200 2010~, US500 1979~)로 정책 아키타입을 실제 약세장에서 OOS 검증.

## 13. FDR 장기 실지수 백테스트 (`fetch_index_history.py`)
- **동기**: §6 부트스트랩·§12 walk-forward 모두 5년 펀드 데이터에 묶여 *실제 약세장*을 못 보고 fold가 적음. FinanceDataReader 장기 실지수로 정책 아키타입을 실약세장에서 OOS 검증 + WF fold 확대(직교 검증층, 코어 펀드 파이프라인 대체 아님).
- **데이터/가드**: US500·IXIC(1979~)·KS200(2010~)·USD/KRW(2003~) 가격지수 → ①배당수익률 평탄 가산(TR 근사) ②US자산×USD/KRW(KRW 언헤지, 추천 UH펀드 정합) ③월말(ME) 리샘플 후 결합(비동기 캘린더 아티팩트 차단) ④월간 전용 `sim`(ppy=12, 가중치 i+1 적용=룩어헤드 차단). SOX 미제공→반도체 IXIC흡수, 나스닥100(NDX) 2020~단기→IXIC(종합) 대용(caveat).
- **매핑(추천 슬롯→지수)**: 다자산 `US500 22/IXIC 21/KS200 22/예금 35`(2010~), US-only `US500 33/IXIC 32/예금 35`(2003~, GFC 포함).
- **실증 ①아키타입(위험조정 우위 재확인)**: 다자산 2010~ 추천 Sharpe 1.35·MDD −12.9% vs 주식100% Sharpe 1.17·MDD −21.8%(CAGR는 주식100%가 높음 — 추천은 *수익↓ 위험조정↑*). US-only 2003~ 추천 Sharpe 1.14 vs 0.94.
- **실증 ②위기별 MDD(5년 데이터 불가 구간)**: 2008 GFC 추천 −15.0% vs 주식100% −23.3%(방어 +8.3%p). 2011/2015/2018/2020/2022 모두 추천이 +2.5~7.3%p 방어. **고정 65/35의 하방방어가 실약세장에서 실증됨.**
- **실증 ③장기 walk-forward(통계력 보강)**: 위험슬리브 4종(동일가중·역변동성·역분산·모멘텀) 학습Sharpe 선택→OOS. fold **12개(다자산)·18개(US-only)** — §12 펀드 WF(6개)의 2~3배. 양쪽 게이트 **FAIL**(OOS Sharpe 사실상 동률, 추천 근소 우위) → *적응적 선택이 고정 추천을 표본외에서 못 이긴다* 결론이 fold 3배로 견고화.
- **한계**: TR 평탄가산은 근사(연도별 배당변동 무시). 지수 아키타입은 자산군 배분 수준(펀드 선택 아님). KS200 2010~ 제약으로 다자산은 GFC 미포함 → GFC는 US-only로 확인. 소스(FDR 스크래핑)는 `index_raw.csv` 캐시 후 사용(라이브 의존성 회피).

## 11. 섹터 로테이션 분석 (`sector_rotation.py`)
- 섹터 = region(미국/한국/중국/인도/일본/유럽/...) + 강한 테마(반도체·바이오의료·국방우주·에너지이차전지·금) 분리.
- 섹터 수익률 = 섹터 펀드들의 분기(3개월) 수익률 평균 ± 표준편차. resample("QE").pct_change.
- **MIN_N=2**(단일펀드 섹터 제외 — 대표성·분배락 과탐 위험) + 브라질 명시 제외(EXCLUDE).
- 산출: 분기별 최고수익 섹터 bar chart(섹터명 라벨·std 에러바·섹터색). 국면 로테이션 정성 진단(거시 신뢰도와 독립).

## 14. 적립·인출 라이프사이클 몬테카를로 (`lifecycle_sim.py`, P1-1)
- **관점 전환**: DC는 수익률 문제가 아니라 **자금조달 문제** — 평가 지표를 CAGR/Sharpe에서 **고갈확률(ruin)·자금충족률(funded ratio)** 로 상향. 월 부담금 적립(~은퇴월) → 30년 실질 지출 인출(인플레 연동)을 하나의 경로로 잇는다.
- **수익 모델(경로 밖 기대수익 주입 금지)**: §13 월간 KRW TR근사 패널의 위험슬리브(아키타입 가중 고정)를 **stationary block bootstrap(평균 블록 24개월)** 재샘플. 기반 2종 병기 — `multi2010`(2010~, GFC 미포함)/`us2003`(2003~, GFC 포함). 위험슬리브에 TER(0.8%/y) 차감, 예금 레그는 결정적(명목=π+0.5%p). **기반 패널의 내재 CAGR을 출력에 명시**(그 유지가 최대 가정).
- **산출**: ①고갈확률(95% CI, 다시드 3종 범위) ②은퇴시점 FR=W/PV(실질지출을 실질스프레드로 할인)·P(FR≥1) ③**sequence risk** — 인출 첫 60개월 슬리브 실질수익 사분위(Q1/mid/Q4) 조건부 고갈률 ④**안전인출액** — 동일 부트스트랩 경로 재사용 이분탐색으로 고갈≤10% 최대 월지출.
- **게이트**: 무현금흐름 경로가 손계산 복리와 일치(self-test, 상수·실경로 2케이스) + 다시드 안정성 + '정책 아키타입' 레이블(펀드단위 결론과 구분).
- **실증(2026-07, W0=3.88억·월부담 150만·π3%)**: us2003 fixed65 기준 월 실질 200만 인출 고갈 0.1%/250만 1.7%/300만 7.3%, 안전인출액 월 316만. **glide(65→40)는 고갈확률을 높인다**(250만: 1.7→5.9%) — 30년 인출 지평에선 디리스킹이 지속가능성을 해침(sequence 방어 < 기대수익 손실). sequence risk 실증: 300만 인출 시 Q1 21% vs Q4 1%.
- **한계**: 세금(퇴직/연금소득세)·IRP 전환 미반영(지출은 세전 필요액으로 해석). 부담금 기본값은 가정(사용자 입력 필수). 예금금리 상수 근사.

## 15. 실질수익 병기 + 비용 드래그 (P1-2/P1-3, 보고서 의무 섹션)
- **실질수익(`real_report.py`)**: 장기 지평에서 인플레는 MDD보다 큰 구매력 파괴 변수. 부트스트랩 경로 분포(mc_results.json)를 π=2/3/4%로 실질 변환(정확식)해 **전략별 실질 CAGR 분포와 P(실질<0)** 을 산출. 예금 슬리브의 실질수익(명목 4.9%·π4% → +0.9%)과 구매력 침식표 병기. 실증: 추천65/35 실질 중앙 5.8~7.9%(π별), P(실질<0) 4~9% — 동일가중·트렌드류는 π4%에서 30%+.
- **비용 드래그(`fee_drag.py`)**: TER은 확실한 마이너스 알파. 총자산 가중 TER(예금 TER 0)·연간 보수(원)·FV=W0×(1+g−TER)^30 비교. 게이트: 코드 미매칭 0(fund_fees.json SoT). 실증(2026-07): 현재보유 0.713% vs B안 0.516% → 30년 +0.46~1.38억(총수익 3~7% 가정).
- **의무화**: 분기 보고서는 ①명목/실질 병기 ②비용 드래그 섹션을 포함해야 완료로 간주.

## 16. 정책 엔지니어링 실증 (P2 — rebalance_policy·fx_overlay·stress_lifecycle)
- **리밸런싱(`rebalance_policy.py`, v2 2026-07-19)**: 2버킷 월간 시뮬로 cal3/6/12(+오프셋)·band±3/5/7·부분복원(d50/d875)·현금흐름(부담금→언더웨이트, 매도 없음) 비교, 게이트=연속리밸(비용0)이 단일수익률 복리와 경로 일치. **실증: 고갈확률은 정책 간 차이가 시드 노이즈 이내(무차이), 회전율만 4배 차이**(cont 22.5% vs cashflow 4.8%/y, us2003) → 정책 선택 기준은 수익이 아니라 비용. 채택: **현금흐름 리밸 + 밴드 ±5%p + 부분복원 d875**(이탈 시 목표±밴드×0.875 지점 복원 — Vanguard 2024 'Rebalancing Edge' 200/175식, 회전율 6.4→5.4%/y·고갈 무차이). v2 추가 실증: ①**타이밍럭**(Hoffstein·Faber·Braun 2020) — 캘린더 오프셋 간 고갈 스프레드 ≤0.02%p·말기자산 ≤0.6%로 정책 비교 결론에 무해 ②**비용 모델 민감도** — 명시 수수료 0(DC 실제)·T+8 결제지연(out-of-market) 극단에서도 고갈 변화 ≤0.03%p, 순위 불변 ③말기자산 우위(d875 +7%)는 위험노출 잔존의 부산물 — '수익 개선' 주장 금지, 채택 근거는 회전율·지연 리스크 감소만. **펀드 레벨 밴드는 5/25 규칙**(min(절대 5%p, 목표×25%), Daryanani 2008 상대 20% 최적·Swedroe 5/25) — 절대 단독은 4~7% 위성에 트리거 불능, ips_check/drift_check에서 적용(2버킷 시뮬은 65% 목표라 검증 불가·골드/신흥국 지수 부재로 7버킷 불가 — 한계 명시). 문헌 근거 상세: `reports/2026Q3/(20260719)_리밸런싱_정책_개선안_근거분석.md`.
- **환헤지(`fx_overlay.py`)**: 단계별 트리거(1500/1400/1300/1200→30/50/70/80%)를 2003~ 실측. **기각** — UH 대비 CAGR −1.5(비용0)~−3.2%p(비용2%), GFC MDD −47.9% vs UH −23.3%. 원화 약세=위기 동행이라 USD 언헤지가 자연 헤지. 게이트=UH(h=0)가 monthly_returns KRW 언헤지와 일치. 한계: 캐리 무시(비용 파라미터로 흡수)·22년 단일 경로.
- **스트레스(`stress_lifecycle.py`)**: 시간가변 π 엔진(게이트=상수 π에서 lifecycle_sim과 고갈확률 일치). 실증(us2003·250만/월): baseline 1.9% → **GFC 은퇴직후 주입 5.5%(3배)** → 인플레쇼크(6%/10y) 4.8% → **저수익 10년(실질0) 56.6%** — 고갈위험의 지배 변수는 변동성이 아니라 *인출 초기 저수익*. ## 17. 거버넌스·자동화 (P3 — IPS·분기 러너·대시보드)
- **IPS**: `status/ips_policy.json`(기계판독) + `templates/ips.md`(인간용) 쌍. 정책 수치는 반드시 검증층 실증으로 채움(glide 기각·현금흐름 리밸·UH 유지 근거 명기). `ips_check.py`가 6항목 자동 판정(위험≤70·단일≤40·밴드 5/25·펀드5~7·TER≤0.60·신흥국≤8), FAIL 시 exit 1(전환기 정상 — drift_check 괴리표로 조치). 밴드 5/25 = min(절대 band_pp, 목표×band_rel_frac), 하한 0.5%p — 월 1회 drift_check 경량 look 병행("자주 보되 드물게 거래").
- **분기 러너(`run_quarterly.py`)**: update_nav→가공→검증→추천→백테스트→실질/비용/드리프트/IPS→대시보드 데이터까지 1커맨드, ips_policy의 targets 자동 주입, `reports/YYYYQn/(날짜)_분기점검_체크리스트.md` 자동 생성. 데이터 단계 실패 시 중단, 분석 단계는 기록 후 계속. collect_nav.py는 data_raw/ 최신 CSV 자동 선택.
- **대시보드**: `extract_dashboard_data.py`가 lifecycle/real/fee/ips 결과를 `DATA.summary`로 임베드 → 요약 카드(안전인출액·고갈확률·실질CAGR·P(실질<0)·TER 현재→목표·IPS PASS). 골드 펀드 추가, **B안 코어-위성 프리셋**(IPS 목표배분) 탑재.
