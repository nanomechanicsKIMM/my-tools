# pension-review 방법론

## 1. 데이터 — KOFIA 일별 NAV
- 출처: dis.kofia.or.kr proframeWeb XMLSERVICES(COMFundPriceModSO.priceModSrch), 표준코드 무인증.
- 일별 요청당 ~120영업일 캡 → `to` 이동 페이지네이션으로 5년치 수집.
- 응답 필드: standardDt(기준일), standardCot(기준가), standardassStdCot(과표기준가), kospi/kospi200/kosdaq 지수.
- **분배금 필드 없음** → 분배락은 기준가 패턴으로 추정(아래).

## 2. 분배락 보정 (수정기준가)
- 한국 펀드는 결산 시 분배 후 기준가를 ~1000으로 리셋 → 원기준가에 가짜 폭락.
- 탐지 규칙: `|nav − 1000| ≤ 1.5 AND nav[d−1]/nav[d] ≥ 1.003`.
- 보정: 분배락일 계수(nav[d]/nav[d−1])를 이전 전구간에 누적 곱(후방조정) → 일일수익률 보존.
- **한계(검증됨)**: tax_nav·시장지수·factor 가드 모두 분배/시장변동 구분 불가. 정탐/과탐이 모든 factor 범위에 혼재. 1000 외 리셋 펀드(리츠 등)는 미탐지. **기준가 데이터만으로 완전 해결 불가** → KOFIA 분배내역 API가 유일 근본해법. 단 일일수익률 기반 백테스트엔 영향 제한적.

## 3. 패널 — NaN 정책
- 날짜×코드 wide 패널, 결측 ffill **금지**.
- 결측 의미: 자격밖(설정전/데이터끝후)·내부공백(휴면)·산발누락.
- 효과: **룩어헤드·생존편향 암묵 차단**(미설정 펀드 자동 후보 제외). lag0≈lag1로 검증.

## 4. 백테스트 엔진 — forward-pricing
- 신호는 T일 종가 NAV까지, 체결은 T+execution_lag NAV → 룩어헤드 차단.
- TER 재차감 금지(NAV에 이미 반영). cost_bps는 펀드 교체 거래비용만.
- 보유 중 NaN(휴면)은 직전가 동결 평가(navff).
- **경량엔진(mc_backtest.fast_run)**: 리밸 구간 벡터화. 신생펀드 0×NaN 전파를 `nan_to_num`으로 차단(전체 283 NaN 패널 필수).

## 5. DC 규제 제약
- 위험자산 ≤70%, 단일펀드 ≤40%. 잔여=현금(또는 예금).
- code→riskAsset 매핑: `_metadata.json` name → `fund_classification.json`.
- 적용 순서: 단일캡 → 위험합 비례축소 → 잔여 현금. 위험조정성과(Sharpe·MDD) 개선 효과.

## 6. 다중경로 — Stationary Block Bootstrap
- 일별 수익률을 가변 블록(평균 L=40일)으로 리샘플 → N개 합성 경로.
- 변동성 군집·횡단 상관 보존, 시간 순서 제거 → **강세장 편향 제거**.
- 하위 경로(CAGR 하위25%) = 하락장 시나리오. Sharpe 1위 빈도·분포로 강건성 평가.
- 핵심 결과: 추천 고정비중이 단일·다중경로 모두 우위(예금쿠션·저회전·추정오차 면역).

## 7. 슬롯 기반 추천 (5단계)
- ① 안전게이트 ② 연령 위험비중 ③ 핵심-위성 슬롯 ④ 슬롯별 랭킹(최저보수/최대순자산) ⑤ 컴플라이언스.
- 추천 6/6 재현 검증. 시점별 동적 선택 → proxy 문제 자연해결, 고정 추천 능가(Sharpe 1.409 vs 1.352).
- 비중(22/13/15/8/7/35)은 최적화 아닌 하향식 규칙 휴리스틱(연령·한도·코어우위).

## 8. 글로벌 분산
- 상관매트릭스: 미국 3자산 고상관(0.77~0.80=1베팅), 한국 KOSPI-가치 0.94 중복, 중국·인도 저/음상관(진짜 분산재).
- 신흥국: 인도(고수익+저상관, Sharpe 0.95) > 중국(분산되나 수익 약).
- **정량+정성 교차검증 필수**: 백테스트 일별상관(인도 0.26)은 실제 장기상관(0.62)을 과소평가 → `/deep-research`로 고평가·환율·상관 보정. 신흥국 ≤8%, 환헤지·DCA.

## 9. 알려진 한계
- 분배락 탐지 휴리스틱(1년+ ±수%p 오차).
- 생존편향: 현재 가입가능 펀드만 수집(과거 청산 펀드 부재).
- proxy 펀드(신생 미국펀드는 동적 슬롯 선택으로 완화).
- 과거 강세 편향(부트스트랩도 원본 분포 기반).
- 신흥국 분산효과 일별 백테스트 과대평가 가능.
