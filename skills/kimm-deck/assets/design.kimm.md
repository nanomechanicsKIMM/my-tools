# KIMM 워크숍 덱 디자인 시스템

국제 공동 R&D 과제 보고·워크숍용 영문 덱 양식. 흰 배경 + 네이비 구조색 +
시맨틱 상태색(녹/황/청/주황)으로 구성된 보고서형 디자인.

> **적용 방법**: 새 덱 생성 시 이 문서 전체를 LLM 컨텍스트에 넣고
> "design.kimm 양식으로" 라고 지시한다. python-pptx 기준 좌표는 `Inches()`.

| 항목 | 값 |

## 4. 공통 페이지 크롬 (모든 콘텐츠 슬라이드)

1. **카테고리 칩** — `(0, 0)` w 1.98 × h 0.40 in, `navy` 솔리드, 흰 Bold 14pt 중앙.
   섹션 라벨: `Project overview` / `Outputs` / `KIMM summary` / `MIT summary` /
   `Demonstration` / `Partner summary` 등.
2. **제목** — `(0.25, 0.35)` w ≈ 9.4 × h 0.62 in, Trebuchet MS Bold 31pt 좌측 정렬.
   제목 아래 y ≈ 1.0 in에 전폭 헤어라인 룰 1개(회색 `7F7F7F`, 두께 ≈ 0.014 in).
   (밑줄형 액센트 라인 금지)
3. **결론 배너** (해당 슬라이드만) — 검정 헤어라인 2개 `(0.62, 6.47)`·`(0.62, 7.05)`
   w 8.26, 사이에 `➡ 한 문장 결론` Trebuchet MS Bold 20pt `navy` 중앙 정렬.
4. **푸터** (레이아웃/마스터) — y ≈ 7.25 in 회색 바: 좌측 과제명(회색 Bold),
   우측 `‹#›` 페이지 번호. 신규 생성 시 근사 사양(추정 — 샘플 덱 검증값):
   바 `(0, 7.28)` 10 × 0.22 in `A6A6A6`, 좌측 텍스트 11pt Bold `595959`,
   우측 `panel-dark` 박스 `(8.85, 7.25)` 1.15 × 0.28 in에 흰 11pt 페이지 번호.

## 5. 슬라이드 아키타입

### A. 표지
- 전면 배경 이미지(주제 관련, 어두운 톤) + 좌상단 프로그램명 흰 Bold 20pt(w 9.6).
- 제목: 흰 Bold 34pt 중앙, y ≈ 1.2, w 9.6.
- 날짜 바: `03031B` 솔리드, 흰 텍스트, `(1.9, 3.37)` w 6.3 × h 0.55.
- 참가기관 패널: `panel-dark` 솔리드, `(1.2, 4.2)` w 7.6 × h 2.7,
  흰 24pt `기관명 <탭> 대표자` 목록.

### B. 목표-실적 표 슬라이드
- 표: `(0.09, 1.10)` w 8.78. 헤더 행 h 0.55(`mid-blue` 배경·흰 Bold 14pt),
  데이터 행 h 0.36(2줄 셀은 0.56), 본문 14pt, `band-blue`/흰 줄무늬.
- 미측정 값은 `NA`를 `alert-red`로.
- 우측 x 8.88에 담당 기관/책임자 라벨 — `navy` Bold 13pt, **해당 행 중앙에 정렬**
  (k번째 데이터 행 라벨 y = 1.10 + 0.55 + 0.36×(k−1)).
- **모든 셀은 한 줄로 유지** — 한 셀이라도 2줄로 꺾이면 행높이가 늘어나
  우측 라벨 정렬이 전부 틀어진다. 내용을 줄이거나 열 폭을 조정할 것.

### C. 요약 2박스 (기관·책임자별 성과)
- 좌우 2열: 헤더 바 `(0.35|5.17, 1.22)` w 4.48 × h 0.42, 검정 배경·흰 Bold 16pt
  `이름 (WP, 주제)`.
- 본문 박스 바로 아래 h ≈ 4.2, 흰 배경 + `border-gray` 1pt 테두리, 15pt,
  구조: `KPI :` → `Year 2 result` → `Update, 날짜` → `Next step/Open item` → `Outputs :`.
- 하단 결론 배너 필수.

### D. 스탯 카드 2×2 (Where we stand)
- 카드 4장 `(0.35|5.17, 1.22|3.70)` w ≈ 4.5 × h 2.28, 흰 배경 + `border-gray` 테두리,
  상단 액센트 바 h 0.07 (시맨틱 색 = 카드 상태).
- 내부: 숫자 40pt Bold(액센트 색) → 제목 16pt Bold → 부연 13–14pt 2줄.

### E. 마일스톤 + 요청 카드
- 좌측 타임라인: 세로 룰 `timeline-gray` x 0.92 (y 1.66–5.81, w 0.03),
  **원형(OVAL)** 도트 0.16 in 시맨틱 색, 날짜 Bold(도트와 같은 색) + 설명 14pt `ink`.
- 우측 요청 카드 3장 `(5.17, 1.56+1.44k)` w 4.48 × h 1.24: 좌측 색블록 w 0.52
  (흰 숫자 22pt), 흰 본체(제목 16pt Bold + 본문 13pt), 도트와 색으로 연결선.

### F. 파트너 소개
- 인물 사진 좌상 `(0.5–0.7, 1.1)` h ≈ 2.2 + 우측 소개 박스(불릿: 이름·소속·전문·웹).
- 하단 3패널 `(0.2|3.5|6.7, 3.45)` w 3.10 × h 3.4–3.8: 연블루 틴트 배경 +
  `mid-blue` 테두리, 패널 제목 Bold 14–16pt 중앙, 이미지 + 12pt 불릿.
- 칩은 `Partner summary`.

### G. 3열 상태 보드 + 요청 박스
- 컬럼 헤더 3개 `(0.35|3.47|6.59, 1.22)` w 2.98 × h 0.42 — `good-green` /
  `warn-amber` / `neutral-gray` 배경, 흰 Bold 15–16pt `상태명 (건수)`.
- 본문 박스 h 3.13, 흰 배경 + `border-gray`, 14pt 목록(항목 + 들여쓴 수치).
- 요청 박스 `(0.35, 5.02)` w 9.30 × h 1.18: `cream` 배경 + `warn-amber` 테두리,
  제목 `warn-amber` Bold 16pt + 본문 13pt.

### H. 클로징
- 배경 이미지 밴드(y 1.0–5.5) 위 중앙에 `panel-dark` 패널 `(0.5, 2.55)` w 9.0 × h 1.55:
  흰 Bold 30pt 인사말(한 줄) + `sub-gray` 16pt 부제(행사명 · 날짜).

## 6. 작성 수칙 (2026-08-08 샘플 재현 검증에서 확장)

- **도형 그림자 금지**: python-pptx `add_shape()`는 테마 `<p:style>` 그림자를
  달고 나온다(`shadow.inherit=False`만으로는 LibreOffice 렌더에서 안 사라짐).
  저장 후 슬라이드 XML에서 `<p:style>…</p:style>`를 제거하는 후처리를 넣을 것.
  원본 덱은 전부 무그림자.
- **한글 본문 들여쓰기는 공백으로 하지 말 것**: 박스 폭에서 줄바꿈되는 순간
  정렬이 깨진다. 문장을 한 줄에 맞게 줄이거나 단락 들여쓰기를 사용.

- 내용은 영어(국제 공동과제), 결론 배너는 반드시 "한 문장 + ➡".
- 폰트를 키우기 전에 박스 폭을 확인 — 좁은 캡션(≤1.2 in)은 12pt 유지.
- 표가 콘텐츠 영역(y 6.4)을 넘으면 폰트가 아니라 **행높이·표 위치**를 조정.
- 색은 §2 토큰만 사용, 상태 의미와 어긋나는 색 배치 금지.
- 자동 하이픈 금지(수동 줄바꿈으로 해결). LibreOffice 렌더 QA 시 하이픈은 무시.
- 생성 후 QA: `soffice --headless --convert-to pdf` → `pdftoppm -jpeg -r 100` →
  전 슬라이드 육안 확인(넘침·정렬·대비).

## 7. 관련 자산 (스킬 내)

- `assets/kimm_deck.py` — 색 토큰·chip/title/banner/footer/box/text/dot 헬퍼 +
  그림자 제거 포함 `save()`. 새 덱 스크립트는 `from kimm_deck import *`로 시작.
- `assets/example_deck.py` — 아키타입 A·B·C·D·E·G·H를 모두 쓰는 검증된
  7슬라이드 레퍼런스 (`python3 example_deck.py out.pptx`). F(파트너 소개)만 미검증.
- 16:9 범용 레이아웃이 필요하면 별도의 `pptx-layout-kits` 스킬을 사용
  (이 양식과 좌표 체계가 다름 — 혼용 금지).
