# NRF 기술수요조사서 자동 생성 스킬

NRF 미래개척융합과학기술개발사업 기술수요조사서 양식(HWPX)을 자동으로 채워 생성하는 스킬.

## Triggers

`기술수요조사서`, `tech survey`, `NRF 수요조사`, `기술수요`, `미래유망융합기술`, `기술수요조사서 작성`

## Workflow

### Phase 1: 기본 정보 수집 (대화)

사용자에게 순차적으로 확인:

1. **제안자 정보** (필수)
   - 기관명, 부서/직급, 성명, 연락처(직장전화, 이메일, 휴대전화)
   - 기본값: 한국기계연구원 (사용자 확인 후 적용)

2. **지원유형** (필수, 택1)
   - 도전형 / 유망신기술형

3. **기술 주제** (필수)
   - 기술명 (한 줄)
   - 핵심키워드 국문/영문 (각 5개 이상)

4. **기술후보군 선택** (필수, 택1)
   - 도전형 13개 + 유망신기술형 6개 중 선택
   - 자율주제 선택 가능

5. **융합 분야** (필수)
   - 대분류 2개 이상, 중분류 2개 이상

### Phase 1.5: 기술 구체화 (구조화 인터뷰)

질문 1개씩 순차 진행:

| 질문 | 매핑 필드 | 필수 |
|------|----------|------|
| 이 기술이 해결하려는 핵심 문제는? | 제안취지, 연구개발개요 | Y |
| 현재 기술의 한계/병목은? | 핵심기술내용, 제안취지 | Y |
| 핵심 요소기술 2~4개 나열 | 핵심기술내용, 기술기능범위 | Y |
| TRL 착수/종료 수준 | TRL | Y |
| 단계별 목표 구분 | 최종/1단계/2단계 목표 | Y |
| 국내외 유사연구 대비 차별점 | 동향 | 선택 |
| 참고 키워드/논문 | Scholar 검색 입력 | 선택 |
| 예상 연구비 및 단계별 배분 | 예산 | Y |
| 파급효과 (산업/사회적) | 파급효과 | 선택 |

선택 질문 스킵 시 AI가 자동 생성.

### Phase 1.7: Google Scholar 기반 연구동향 조사 (자동)

1. 기술 주제 + 요소기술 키워드로 검색 쿼리 2~3개 자동 구성
2. WebSearch로 최근 3~5년 논문 검색 (쿼리당 상위 5~10건)
3. 국내/해외 분류 후 동향 초안 자동 작성 (□/◦/- 구조)
4. **검색 결과에 없는 논문 인용 금지**

### Phase 2: AI 내용 생성 (자동)

Phase 1.5 답변 + Phase 1.7 검색 결과를 컨텍스트로 프롬프트 구성.
`prompts/survey_prompt.md` 템플릿 기반으로 각 섹션 내용 생성.

### Phase 2.5: 초안 검토/수정 (대화)

생성된 내용을 섹션 단위로 사용자에게 미리보기 제공:
- 연구개발개요 (300자)
- 핵심기술내용
- 최종/단계별 목표
- 국내외 동향 (인용 논문 목록 포함)
- 파급효과

수정 요청 시 해당 섹션만 재생성.

### Phase 3: JSON 조립 + HWPX 빌드 (자동)

```bash
PYTHONUTF8=1 uv run python scripts/build_survey.py --input data.json --output result.hwpx
```

### Phase 4: 검증 + 결과 전달

- validate.py 자동 실행
- 생성된 HWPX 파일 경로 안내
- **한글(HWP)에서 열어 양식 유지 확인 권장**

## 기술후보군 목록

### 도전형 (13개)
1. 환경 적응형 자율연산 플랫폼
2. 글래스 프리 공간 지능 플랫폼
3. 정보 저장‧처리용 바이오 컴퓨팅
4. 상황 이해형 차세대 감각 입력‧해석
5. 다중감각-인간증강 센서-인터페이스
6. 극한 환경 제조
7. 그린 희토류 자원화
8. 단백질 미세구동체 집단 행동 설계
9. 구조 설계 기반 스마트 메타물질
10. 솔리드 스테이트 냉각
11. 협력형 에너지 하베스팅
12. 양자에너지 전송(QET)
13. 도전형 자율주제

### 유망신기술형 (6개)
1. 상태유지형 뉴로모픽 컴퓨팅
2. 인공근육 액츄에이터
3. 제로 파워 모션 디스플레이
4. 구조형 배터리 복합 소재
5. 해수 기반 에너지 저장‧전환
6. 유망신기술형 자율주제

## 제약사항

- 5페이지 이내 (양식 규격)
- 멀티라인 텍스트는 □/◦/- 계층 구조 형식
- 연구개발개요는 300자 이내
- 체크박스는 □→■ 변환
- fix_namespaces.py 후처리 필수
