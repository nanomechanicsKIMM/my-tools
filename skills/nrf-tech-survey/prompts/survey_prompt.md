## 생성 섹션

### 1. 연구개발개요 (300자 이내)

**형식**: 단일 문단, 서술형
**내용 구조**:
- 1문장: 기술 배경/필요성
- 2문장: 핵심 기술 내용
- 3문장: 목표 및 기대 성과

**제약**: 정확히 300자 이내. 초과 시 축약.

### 2. 핵심기술내용

**형식**: □/◦/- 계층 구조
**분량**: 10~15줄

```
□ 핵심기술 1
  ◦ 세부 설명
    - 구체적 기술 사양/방법
    - 정량적 목표 포함
□ 핵심기술 2
  ◦ 세부 설명
    - 구체적 내용
```

**지침**:
- 요소기술 각각에 대해 □ 항목 1개
- 각 □ 아래 ◦ 1~2개, 각 ◦ 아래 - 1~3개
- 정량적 수치 포함 (감도, 효율, 크기 등)

### 3. 기술기능범위

**형식**: □/◦/- 계층 구조
**분량**: 8~12줄

```
□ 기능 영역 1
  ◦ 구체적 기능/범위
□ 기능 영역 2
  ◦ 구체적 기능/범위
```

**지침**:
- 연구 범위를 기능 단위로 구분
- 포함/미포함 범위 명시

### 4. 최종목표

**형식**: 단일 문장 (1~2줄)
**내용**: 최종 TRL 수준 + 핵심 성과물 명시

### 5. 1단계 목표 (1~2년차)

**형식**: 단일 문장 (1줄)
**내용**: 기초/원천 기술 확보 수준 + 중간 TRL

### 6. 2단계 목표 (3~5년차)

**형식**: 단일 문장 (1줄)
**내용**: 시스템 통합/실증 수준 + 최종 TRL

### 7. 연구개발내용

**형식**: □/◦/- 계층 구조
**분량**: 12~18줄

```
□ 1단계: [주제]
  ◦ 세부 연구내용 1
    - 구체적 방법/접근
  ◦ 세부 연구내용 2
□ 2단계: [주제]
  ◦ 세부 연구내용 1
  ◦ 세부 연구내용 2
```

**지침**:
- 1단계/2단계로 명확히 구분
- 각 단계 목표와 연계

### 8. 제안취지

**형식**: □/◦/- 계층 구조
**분량**: 8~12줄

```
□ [필요성 1]
  ◦ 근거/데이터
□ [필요성 2]
  ◦ 근거/데이터
□ 기존 기술 한계 극복 필요
  ◦ 한계점 설명
```

**지침**:
- 시장/사회적 필요성 + 기술적 필요성 균형
- 정량적 데이터 포함 (시장 규모, 성장률 등)

### 9. 국내동향

**형식**: □/◦/- 계층 구조
**분량**: 8~12줄
**소스**: Scholar 검색 결과 (국내논문) 기반

```
□ 국내 연구 현황
  ◦ [기관/대학] 중심 연구 동향
    - 저자 et al.(연도), 핵심 내용 (학술지명)
  ◦ [연구 흐름 요약]
```

**지침**:
- 검색된 국내 논문 인용 필수
- 검색 결과에 없는 논문 인용 금지
- 부족 시 "국내 연구는 초기 단계" 등으로 보완

### 10. 해외동향

**형식/분량**: 국내동향과 동일
**소스**: Scholar 검색 결과 (해외논문) 기반

### 11. 파급효과

**형식**: □/◦/- 계층 구조
**분량**: 6~10줄

```
□ 산업적 파급효과
  ◦ 구체적 효과 1
  ◦ 구체적 효과 2
□ 사회적 파급효과
  ◦ 구체적 효과
```

### 12. 특이사항

**형식**: □/◦/- 계층 구조
**분량**: 4~6줄
**내용**: 산학연 협력, 기업 참여, 특수 인프라 등
