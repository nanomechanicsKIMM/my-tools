# IFR 평가 매트릭스

## 평가 기준

| 기준 | 가중치 | 설명 |
|------|--------|------|
| 실현 가능성 (Feasibility) | 0.25 | 현재 기술 수준에서 구현 가능한 정도 (1: 불가능 ~ 10: 즉시 구현) |
| 비용 효율 (Cost) | 0.15 | 개발 및 제조 비용 대비 효율 (1: 매우 비쌈 ~ 10: 저비용) |
| 기술적 효과 (Effect) | 0.25 | 문제 해결 효과의 크기 (1: 미미 ~ 10: 완전 해결) |
| 특허성 (Patentability) | 0.20 | 진보성 + 신규성 (1: 공지기술 반복 ~ 10: 선행기술에서 유추 불가) |
| 산업적 가치 (Industrial Value) | 0.15 | 시장성, 라이선싱 가능성 (1: 무가치 ~ 10: 고가치) |

> [!note] 이상성(Ideality) 보조 지표
> 이상성 = 유익효과 / (비용 + 유해효과). 발명 초기 단계에서 수치로 산정하면 false precision(허위 정밀도)을 유발하므로 **정성 3단계(高/中/低)로만** 표기하고 가중 종합점수 계산에는 반영하지 않는다 — 순위 판단을 위한 참고용 보조 컬럼이다.

## 특허성 세부 평가 (신규성·진보성·실현/뒷받침 3분해)

특허성(P) 축은 아래 3개 하위 점수의 산술평균으로 산정한다: **P = (신규성 + 진보성 + 실현·뒷받침) / 3**

> [!note] 잠정 점수 고지
> Phase 4 시점(선행조사 이전)의 신규성·진보성 하위 점수는 잠정치다. Phase 5 완료 후 Phase 5.5에서 신규성 하위 점수를 ifr_coverage 기준으로 재채점한다.

### 하위 점수 판단 기준

| 하위 축 | 배점 기준 |
|--------|----------|
| 신규성 | Phase 5 `ifr_coverage`와 정합 — novel(미개시)=8~10, partial(부분개시)=4~7, disclosed(개시됨)=1~3. Phase 5 이전(Phase 4 시점)에는 기술 분야 일반 수준 기준 잠정 점수 |
| 진보성 | 3논거(①결합 곤란성 ②상승효과 ③teaching away) 중 성립하는 논거 개수 기준 — 3개 성립=9~10, 2개=7~8, 1개=5~6, 0개(단순 조합)=1~4 |
| 실현·뒷받침 (112a) | §6 실시예로 재현 가능한 구체성 — 구체적 수치·재료·공정까지 서술 가능=9~10, 개략적 구조만 서술 가능=5~6, 실시예로 재현 불가=1~4 |

> [!note] 가중치 민감도 확인
> 5축 가중치(0.25/0.15/0.25/0.20/0.15)를 ±0.05 범위로 조정했을 때 상위 3개 IFR의 순위가 역전되는지 1회 확인 — 역전되면 순위 차가 근소함을 보고서에 명시(단일 가중치 세팅에 대한 과신 방지)
