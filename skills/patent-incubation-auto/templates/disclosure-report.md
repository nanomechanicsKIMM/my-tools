# {{발명명칭}} — 발명내용설명서

> [!important] 공통 작성 규칙 (모든 본문 섹션 §3~§8 공통)
> 1. **개조식 문체 필수**: 모든 문장을 `~함.`, `~있음.`, `~필요함.`, `~됨.`, `~임.` 등으로 종결한다. `~이다`, `~한다` 등 평서체 금지.
> 2. **상세 설명 필수**: 짧게 자르지 말고, 한 문장 안에 조건·수치·재료·메커니즘·인과를 구체적으로 담는다. "상세한 설명이 추가된 개조식"이 본 양식의 핵심.
> 3. **§6 계층적 글머리기호 필수**: `6.1 / 6.2 / 6.1.1` 숫자 하위섹션 금지. markdown `- ` 사용, 공백 2칸 = 1 레벨. HWPX 변환 시 ●/○/▪/- 계층 bullet과 들여쓰기로 자동 렌더링됨. 연속 문단은 bullet과 같은 레벨로 정렬되어 글머리기호 위치에 맞춘 hanging indent가 유지됨.
