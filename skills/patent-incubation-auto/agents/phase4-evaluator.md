# Phase 4: 정량 평가 & 순위화

## 입력

1. `invention_manifest.json`의 `input` 필드
2. `triz_analysis.json` (Phase 2 출력, 사용자 검토 후 확정본)
3. `templates/evaluation-matrix.md` (평가 템플릿)

## 작업

### 평가 기준 (5항목, 각 1-10점)

| 기준 | 가중치 | 평가 기준 |
|------|--------|-----------|
| 실현 가능성 (F) | 0.25 | 현재 기술로 구현 가능한 정도 |
| 비용 효율 (C) | 0.15 | 개발·제조 비용 대비 효율 |
| 기술적 효과 (E) | 0.25 | 문제 해결 효과의 크기 |
| 특허성 (P) | 0.20 | 진보성 + 신규성 (선행기술 대비 차별화 정도) |
| 산업적 가치 (V) | 0.15 | 시장성, 라이선싱 가능성, 사업화 가능성 |

### 종합점수 계산

```
종합점수 = F×0.25 + C×0.15 + E×0.25 + P×0.20 + V×0.15
```

### 평가 절차

1. 각 IFR에 대해 5항목 점수 부여 (1-10, 정수)
2. 가중평균 종합점수 계산
3. 종합점수 기준 내림차순 정렬
4. 상위 3개 IFR에 대해 강점/약점 코멘트 추가

### 점수 기준 가이드

**실현 가능성 (F)**:
- 9-10: 기존 기술/장비로 즉시 구현 가능
- 7-8: 약간의 개발 필요하나 기술적 장벽 낮음
- 5-6: 추가 연구개발 필요
- 3-4: 핵심 기술 미확보, 상당한 개발 필요
- 1-2: 현재 기술로 구현 불가능

**비용 효율 (C)**:
- 9-10: 기존 공정에 최소 비용으로 적용
- 7-8: 합리적 투자로 구현 가능
- 5-6: 중간 수준의 설비/재료 투자 필요
- 3-4: 고비용 장비/소재 필요
- 1-2: 경제성 확보 어려움

**기술적 효과 (E)**:
- 9-10: 핵심 과제를 완전히 해결
- 7-8: 대부분의 과제를 효과적으로 해결
- 5-6: 부분적 해결, 보완 기술 필요
- 3-4: 제한적 효과
- 1-2: 미미한 효과

**특허성 (P) — 진보성 + 신규성**:
- 9-10: 기존 기술과 전혀 다른 접근법, 선행기술에서 유추 불가능한 해결 방식
- 7-8: 공지된 요소의 비자명한 조합, 예측 불가능한 효과 발생
- 5-6: 일부 새로운 구성이 있으나 부분적으로 선행기술과 유사
- 3-4: 선행기술의 단순 변형이나 설계 변경 수준
- 1-2: 공지된 기술의 반복, 통상의 기술자가 용이하게 도출 가능

> [!note] 특허성 평가 세부 기준
> - **신규성**: 이 IFR의 핵심 구성이 선행기술에 개시되어 있는가? (동일 구성이 없으면 신규성 있음)
> - **진보성**: 이 IFR의 효과가 선행기술로부터 예측 가능한가? 통상의 기술자가 용이하게 도출 가능한가?
> - Phase 4 시점에서는 선행특허 DB 조사 전이므로, 기술 분야의 일반적 기술 수준을 기준으로 평가
> - 이 단계의 특허성 점수는 **선행조사 이전 잠정 점수**(provisional)이며, evaluation.json에 `patentability_provisional: true`로 표시한다
> - 실제 재채점은 Phase 5(선행특허 조사) 완료 직후 **Phase 5.5**에서 오케스트레이터가 별도 수행 — ifr_coverage(novel/partial/disclosed) 반영. Phase 4 자체는 IFR 집합에 대한 잠정 평가만 담당하며 재채점을 수행하지 않는다

**산업적 가치 (V)**:
- 9-10: 기존 제품/시장에 즉시 적용 가능, 높은 라이선싱 가치
- 7-8: 특정 시장에 적용 가능, 사업화 가능성 높음
- 5-6: 시장 잠재력 있으나 사업화에 추가 검증 필요
- 3-4: 시장이 제한적
- 1-2: 산업적 활용 어려움

## 주의사항

- 평가는 사용자가 Phase 3에서 검토/수정한 IFR 목록을 기준으로 수행
- 특허성(P) 평가는 Phase 4 시점의 일반적 기술 수준 기준의 **잠정 점수**(`patentability_provisional: true`)이며, 선행특허 조사(Phase 5) 완료 직후 **Phase 5.5**(오케스트레이터 수행)에서 ifr_coverage를 반영해 재채점됨 — Phase 4는 재채점을 수행하지 않는다
- 특허성이 높은 IFR(P≥7)은 순위가 다소 낮더라도 별도 표시하여 Phase 6에서 핵심 청구항 후보로 고려되도록 함
