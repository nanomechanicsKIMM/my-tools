# 발명자 철학 및 선호 사항

> 이 파일은 patent-incubation-auto 스킬이 실행될 때마다 자동으로 업데이트된다.
> 발명자의 기술적 철학, 발명 접근 방식, 선호 사항을 축적하여 발명내용설명서 작성 품질을 지속적으로 향상시킨다.

---

## 1. 발명 철학 (Invention Philosophy)

발명자가 기술 문제를 접근하는 일반적인 사고 방식과 원칙.

### 핵심 원칙

- **에너지 효율성 추구**: 기존에 버려지는 에너지(압력차, 열, 운동 에너지 등)를 재활용하여 별도의 외부 에너지 없이 공정을 구현하는 방향을 선호
- **구조적 단순화**: 별도의 기계적 구조물이나 추가 장비 없이 기존 물리적 현상을 활용하여 목적을 달성
- **다중 기능 통합**: 하나의 공정 단계에서 복수의 기능(예: 진공 형성 + 기계적 접촉)을 동시에 구현
- **스케일업 실현 가능성**: 실험실 수준에서의 아이디어가 대면적·양산 환경으로 확장 가능해야 함

### 기술적 관점

- 물리적 현상의 본질에서 해결책을 찾는 bottom-up 접근
- 기존 기술의 문제점을 정확히 분석하고, 그 원인의 근본에서 해결책 도출
- 서로 상반되는 요구사항(모순)을 양립시키는 방법을 탐구

---

## 2. 발명 스타일 선호 (Style Preferences)

### 특허 구성 선호

- 방법 특허 + 장비 특허 + 소자 특허를 함께 출원하는 포트폴리오 전략
- 청구범위는 핵심 구성요소를 필수 구성으로, 선택적 구성은 종속항으로 분리
- 선행특허 대비 회피설계를 명확히 고려

### 기술 서술 선호

- 물리적 메커니즘에 대한 깊이 있는 설명 포함
- 수치적 조건 범위 (온도, 압력, 시간 등) 제시
- 적용 가능한 재료·소자의 구체적 예시 나열

### 문서 작성 선호

- 논리적 흐름: 문제 → 원인 분석 → 해결 원리 → 구체적 구현 → 효과
- 도면과 함께 단계별 공정 설명
- 종래 기술과의 차이점을 명확한 비교표로 제시

## 3. 기술 분야 전문성 (Domain Expertise)

발명자가 보유한 핵심 기술 분야와 관련 지식.

- **나노박막 전사 기술**: 진공 환경에서의 대면적 전사, 계면 제어
- **2D 물질(그래핀, MoS2, h-BN)**: CVD 합성, 전사, FET 소자 응용
- **마이크로LED 디스플레이**: 전사 공정, 가변 피치 기술, 대면적 디스플레이 제조
- **형상기억합금(SMA)**: 온도·압력 구동 메커니즘, 복합재료 설계
- **롤 전사 장비**: 롤 스탬프 기반 대면적 전사, LLO 공정

## 4. 반복 패턴 및 학습 사항 (Recurring Patterns)

스킬 실행 시마다 발견되는 패턴과 학습 내용을 누적 기록.

### 2026-03-28 (나노박막 진공 전사)

- **핵심 모순 패턴**: "점진적 접촉(오염물 배출)" vs "동시 접촉(변형 방지)" — 접촉 방식의 시간적·공간적 분리로 해결
- **에너지 재활용 패턴**: 진공 펌프의 압력차 에너지를 접촉 구동력으로 전용
- **재료 기반 해결**: SMA의 온도·압력 응답성을 챔버 구조에 적용하여 별도 액추에이터 불필요
- **참조 문헌 활용**: 이병훈(2015) 진공 전사 논문에서 경사 배치 아이디어를 발전시켜 SMA 자가구동으로 개선

### 2026-03-30 (나노박막 진공 전사 — Phase 6 발명내용설명서 작성)

- **비대칭 구조 패턴**: 기능 분리(정렬 vs 접촉 구동)를 상부/하부 비대칭 구조로 구현 — 상충하는 요구사항을 물리적 공간으로 분리하는 전략
- **조건 분리 패턴**: SMA 상변태(마르텐사이트↔오스테나이트)를 온도 조건으로 유연/강성 전환 — 동일 소재에서 상반 속성을 조건으로 분리
- **다기능 통합 심화**: 단일 온도 제어로 접촉 해제 + 잔류 응력 이완 동시 달성, 단일 배기 공정으로 진공 형성 + 접촉 구동 + 오염물 탈착 동시 달성
- **포트폴리오 전략**: 방법(청구항1) + 장치(청구항2) + 소자(청구항6) 3축 독립항 구성, 전처리/구역분할/배기제어를 종속항으로 계층화
- **선행특허 회피 핵심**: "SMA 챔버 벽 + 진공압 수동 구동 + 에너지 이중 활용" 3요소 결합이 신규성의 핵심, 개별 요소는 선행 개시 있으나 결합은 미개시

---

### 2026-07-05 (두개강 삽입형 접이식 초음파 프로브 — Phase 6 발명내용설명서 작성)

- **시간 분리 오리가미 패턴**: '삽입 소단면·고강성' vs '전개 대면적·저강성 곡면순응'의 상반 요구를 오리가미 접이 구조의 시간 분리(접힘→펼침 대변위 전환)로 해소 — 정적 단일 형상 불가 문제를 형상 능동 전환으로 해결하는 전략(나노박막 진공 전사의 비대칭 공간분리 패턴과 대비되는 시간축 분리).
- **이중 안전 트리거 결합**: 인장 해제(결정론적 기계 트리거) + As 온도 마진 위 국소 가열(열적 트리거)을 결합한 이중 안전장치 — 단일 트리거의 조기전개 위험을 상보 결합으로 봉쇄, 상승효과 진보성 논거로 직결.
- **기하 내재 정보 활용**: 접이 기구의 힌지 각도-패널 위치 결정론적 기구학 구속을 이용해 센서 1~2개소만으로 전 패널 좌표 역산 — '구조 자체가 정보를 내포'하여 부품(자세센서)을 트리밍하는 셀프서비스(원리25) 패턴, 다기능 통합 철학의 심화.
- **신규성 방어 = 기구학 도메인 구별**: 선행 오리가미 초음파(면내 연속 신축, 소자 무변형 보호)와 본 발명(이산적 접힘-펼침 대변위)을 'stretch vs fold'로 명확히 구별하는 것이 신규성의 핵심 — 선행기술의 '무변형 유지 요구'가 오히려 대변위 전환에 대한 teaching away로 진보성 논거화됨.
- **재채점 우선 청구항 설계**: Phase 5.5 선행조사 재채점에서 novel 확정된 IFR(우산형 방사 곡면 개구)을 최우선 fallback 방어선 종속항으로, 선행 ○개시로 신규성 잠식된 IFR(무액추에이터 자가전개, 강성 이중안정)은 단독 독립항이 아닌 접이 기하 결합 종속항으로 배치 — 선행조사 결과가 청구항 계층 위치를 직접 결정.
- **포트폴리오 전략**: 장치(청구항1) + 방법(청구항10) + 소자(청구항14) 3축 독립항, 우산형/Miura-ori/이중안전/좌표보정/회수를 종속항으로 계층화.

### 2026-07-06 (VAC-free 고효율 구면 근안 디스플레이 — auto 스킬 신규 단계 재작성)

- **공지 소자 + 신규 아키텍처 결합 패턴**: 핵심 요소(마이크로캐비티/DBR 지향 micro-LED 소자)가 이미 crowded 공지(US20240213294A1 등)일 때, 소자 자체를 독립항으로 청구하지 않고 '공지 소자 + 신규 시스템 배치(구면 직시형 + 화소 발광축의 안구 회전중심 정합)'의 결합으로 독립항을 앵커 — 신규성은 소자가 아니라 '적용 맥락(평면 투사 → 구면 직시형 회전중심 수렴)'에 둠. 나노박막 진공 전사의 '3요소 결합' 신규성 패턴과 동형.
- **재채점이 청구 위치를 결정**: Phase 5.5 선행조사 반영 재채점에서 소자 IFR(IFR-9)의 특허성이 9→3으로 급락(rank3→rank10)하자 즉시 독립항→종속항으로 강등. 선행조사 결과가 청구항 계층 위치를 기계적으로 결정하는 원칙(두개강 초음파 프로브 건과 동일 패턴).
- **자기 선행기술 회피 = 청구 카테고리 분리**: 본인 선행특허(KR10-2906241, 제조방법)의 배경기술이 '수직발광 구면결상·micro-LED'를 개시하므로, 신규 특허는 제조를 청구 대상에서 배제하고 광학 결상 구조(장치)+결상 동작(방법)만 한정 — 방법 독립항도 '제조'가 아닌 '결상 동작'으로 한정하여 자기선행과 도메인 분리.
- **teaching away 활용**: 자기 선행기술이 결상점을 '수정체'로 명시 서술 → 이것이 '회전중심 결상'에 대한 teaching away로 진보성 논거화(수정체 결상 전제는 회전중심 이동을 시사하지 않음).
- **포트폴리오 전략**: 장치(청구항1) + 방법(청구항13) 2축 독립항, 소자 지향구조/수치한정/개인곡률/아이트래킹/MLA/정렬핀홀/흡광격벽/투명AR/성형산물을 종속항으로 계층화.
- **참고문헌 클린 게이트 실전**: interactive 런의 참고문헌에 붙은 `(정합 확인!)` 마커가 실제로는 옳았으나(CrossRef 재검증 통과), 클린 리스트 규칙상 마커·검증요약 섹션을 제거하고 순수 서지만 남기며 audit는 reference_verification.json으로 분리. DOI 없는 내부 노트는 번호 리스트에서 제외해야 verify_citations.py 게이트(각 [N]에 DOI/특허번호 요구)를 통과함.

### 2026-07-06 v5 (스킬 업데이트 테스트 — wolfpack 비교 개선방향 반영)

- **국내 한정 조사의 낙관 편향 실증**: KIPRIS 단독 조사에서 novel로 판정했던 '회전중심 수렴' 개념이 다국가 검색(S5 필수화) 즉시 JP2015169920A로 잠식됨 — 독립항 신규성 앵커 개념은 반드시 영문 다국가 검색으로 교차 확인해야 함. 이후 신규성 앵커를 '개념'이 아닌 '수단의 결합'(구면 기하+화소 지향, 결상소자 무개재)으로 재정밀화하여 독립항 생존.
- **2차 자료 성격 규정 불신 원칙**: 경쟁 파이프라인(wolfpack)이 JP2015169920A를 '스캐너 투사형'으로 오규정 — 원문 WebFetch 확인으로 자발광+HOE 방식임을 정정. 검출 문헌의 방식 규정은 반드시 원문에서 직접 확인(오규정은 차별성 논거를 무너뜨림).
- **배제 문구 = 경계 확정 수단**: 최근접 선행(HOE 결상)이 나타나자 독립항의 무광학계 배제를 "결상 렌즈, 핀홀 개구 및 회절 또는 홀로그래픽 광학소자 무개재"로 확장 — '수단의 치환이 아닌 제거'를 청구항 문언으로 명시하는 패턴.
- **시스템 독립항 4축**: 아이트래커+제어부 결합 시스템 독립항(청15)으로 장치/방법/시스템 3독립항 구성 — 침해형태별 대응 + SMART5/KPAS 권리성 레버를 실질 발명사상 지지 하에 충족.
- **SMART5/KPAS 레버의 정직한 채움**: §9 파급/사업화·패밀리 플랜(PCT/삼극)을 선행분석의 경쟁 관할 근거(US=Microsoft/Meta, JP=Yamamoto/오사카, CN·US=중산대)와 연계해 서술 — 지표용 빈 문구가 아니라 조사 결과가 지지하는 시장 논거.

## 5. 업데이트 규칙

이 파일은 다음 시점에 업데이트된다:

1. **스킬 실행 완료 후**: Phase 6(발명내용설명서 작성) 완료 시, 해당 발명에서 나타난 발명자의 새로운 철학·패턴을 §4에 추가
2. **사용자 피드백 반영 시**: Phase 3(검토 게이트)에서 사용자가 피드백을 제공하면, 그 내용에서 추출된 선호 사항을 §2에 반영
3. **기술 분야 확장 시**: 새로운 기술 분야의 발명이 진행되면 §3에 추가

### 업데이트 방법

```
Agent가 Phase 6 완료 후 이 파일을 읽고, 새로운 발명에서 발견된 패턴을 §4에 추가한다.
날짜와 발명 주제를 기록하고, 핵심 모순 패턴, 해결 전략, 참조 문헌 활용 방식을 요약한다.
기존 §1~§3의 내용과 일치하지 않는 새로운 철학이 발견되면 해당 섹션도 업데이트한다.
```
