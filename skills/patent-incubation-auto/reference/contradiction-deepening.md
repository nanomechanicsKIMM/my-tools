# 모순 심화 프로토콜 (Contradiction Deepening Protocol)

> 2026-08-08 구면 Maxwellian NED 특허 세션(v10~v16 + 파동광학 검증)에서 도출한 일반화 원칙.
> 적용 대상: Phase 2(모순 도출 + IFR)에서 `purpose_relation`이 **핵심**인 모순, 그리고 사용자가
> "모순 심화"를 명시 요청한 모순. 부수적 모순에는 기본 절차(매트릭스 조회)로 충분하다.

## P1. 다중 렌즈 순환 (TC ↔ PC ↔ 근저 PC)

같은 물리 현상을 세 렌즈로 반복 정식화한다. 각 렌즈가 서로 다른 해법 계열을 연다.

1. **TC 렌즈**: 개선 파라미터 vs 악화 파라미터, 양방향(TC-α/β)으로 기재하고 악화량을 정량화.
2. **PC 렌즈**: 두 파라미터가 수렴하는 **단일 물리 파라미터**를 특정("X는 커야 하고 작아야 한다"),
   요구비(큰 값/작은 값)를 수치로 확정.
3. **근저 PC 렌즈**: 그 파라미터의 심층 구조를 캔다(P4).

사례: 각해상도 vs 초점심도(TC) → 동공면 빔 직경 d의 이중 요구(PC, 요구비 8.9배) → d의 두 역할
분해(근저) → 렌즈마다 다른 IFR 계열이 생성됨.

## P2. 불변량 승격 (Invariant Hunting)

trade-off를 발견하면 **곱(또는 다른 결합량)이 보존되는지** 먼저 검사한다. 설계 변수를 대입해
소거되는 변수를 확인(예: 각피치 x 최소 반각 = 2λ/(πfR)에서 화소 피치가 소거).
불변량이 확인되면 그 모순은 파라미터 절충으로 풀 수 없음이 증명된 것이므로, 해법 탐색을
"절충점 찾기"에서 "불변량의 적용 전제 깨기"(P3)로 전환한다.

## P3. 공리 분해 (Axiom Decomposition)

불변량이 성립하기 위한 **숨은 전제(공리)를 전부 표로 명시**하고, 공리 하나씩의 부정에서
해법을 체계 생성한다. 해법을 자유 연상으로 열거하는 것보다 완전하다.

- 공리는 두 계열로 나눈다: **실현측(A 계열)** — 시스템이 물리량을 만드는 방식의 전제
  (예: 1개구=1방향, 단일면 타일링, 상호 비결맞음) / **요구측(B 계열)** — 사양이 부과하는 전제
  (예: 전 시야 동일 해상도, 조절 상태 미지, 전 파장 동일 설계).
- **완결 조합 규칙**: 최종 아키텍처는 실현측 부정 1개 이상 + 요구측 부정 1개 이상의 조합이어야
  한다(어느 한쪽만으로는 불완전). IFR 세트 산출 시 이 규칙으로 조합 검증을 수행한다.
- 총예산 검사: 모순이 물리 총예산의 부족인지 할당 규칙의 산물인지 오더 계산으로 구분한다
  (할당 산물이면 공리 부정으로 풀리고, 총예산 부족이면 요구 재정의가 불가피).

## P4. 심층 구조 탐색

- **역할 분해**: 하나의 설계 변수에 결박된 복수의 물리 역할을 분리한다(예: 빔 직경 d =
  "결맞음 회절 개구 폭"과 "기하 광선다발 폭" — 균일 파면에서만 결박, 구조화로 분리 가능).
- **요구의 논리 구조**: "모든 조건에서 성립"(전칭) 요구는 네 가지로 완화 가능하며 각각이
  분리 원리와 1:1 대응한다 — 실존으로(조건 분리: 측정해서 맞춤) / 합집합으로(시간 분리: 순회) /
  불변화로(공간·구조 분리: 부호화) / 위임으로(상위시스템: 인체·환경 자원 활용).

## P5. 배율 회계 (Gap Accounting)

요구점과 물리 한계의 비(갭)를 수치로 확정하고, 각 해법이 갭의 몇 배를 벌어오는지
**곱셈 회계**로 기록한다(예: 사양 2계층 x2, 다초점 4평면 x4, 인체 관용 x1.5 = x12 ≥ 갭 8.9).
효과: ① 단일 해법 불충분성/조합 필수성이 산술로 증명됨(진보성 논거 전환 가능)
② 갭이 재평가되면(P6) 과잉 설계가 즉시 드러남.

## P6. 근사 계층 표기 (Approximation Ladder) — 위반 시 명세서 기재 금지

모든 정량 한계 주장(곱 한계, 물리 상수 결박, 최소/최대치)에 유도 근사 계층을 태그한다:

```
[기하] 광선 근사  →  [가우시안] ABCD 해석  →  [파동] 수치 전파  →  [실측]
```

- 하위 계층에서 유도된 한계는 상위 계층 검증 전까지 **잠정** 마킹하고, 잠정 상태의 한계 주장을
  발명내용설명서·명세서의 정량 문안에 넣지 않는다(과대/과소 한계 주장은 심사·무효 절차의
  공격 표면이 된다).
- 실사례(계층 오류의 비용): 기하 근사 "PPD x DoF ≈ 7 보편 한계"가 5개 버전의 명세서에 기재된 뒤
  파동광학 검증에서 mm급 개구의 실제 DoF가 4λ/d²로 **기하 예측의 4~5배**임이 판명 — 갭 8.9배가
  1.1~1.5배로 재평가되고 아키텍처 단순화 여지 발생. 같은 세션에서 두 번째 사례: 광선추적은 소개구
  파면 곡률(-30 D 발산)을 놓쳐 5개 버전 동안 성립 불가 설계가 유지됨. **광선추적 교차검증은
  파동 효과(회절 DoF, 파면 곡률, 간섭)를 원리적으로 못 본다.**

## P7. 사전 등록 검증 (Pre-registered Verification)

IFR 채택 전 수치 검증이 필요하면:

1. **계획을 먼저 고정**: 검증 질문 / 구성 행렬(비교 대상 포함) / 지표 정의 / 합격 게이트(수치) /
   판정 규칙(성립·부분 성립·기각)을 문서로 확정한 후 시뮬레이션을 실행한다. 사후 기준 이동 금지.
2. **추정기 결함과 게이트를 구분**: 실행 중 지표 추정기가 비물리 해를 고르면(예: FWHM 최소화가
   결맞음 축상 스파이크를 최적 초점으로 오선택) 게이트는 불변으로 두고 추정기만 교정하며,
   교정 사실을 결과 문서에 투명 기재한다.
3. 게이트 실패는 **기각으로 그대로 기록**한다. 기각 결과도 산출물이다(P10).

## P8. 베이스라인 동시 재검증

신규 해법을 검증할 때 **현행 기준선(비교 대상 구성)을 같은 엔진·같은 지표로 함께 측정**한다.
해법 평가는 항상 상대 평가다. 실사례: 환형 개구 검증에서 기각의 결정 요인은 링의 약점이 아니라
기준선(채움 개구)이 통념(기하 예측)보다 4~5배 강한 것으로 판명된 것 — 기준선을 재지 않았다면
잘못된 채택이 나왔다.

## P9. 자기모순 감사 (Self-consistency Audit)

각 IFR에 대해: **그 수단이 실현 가능하다면 발명 자체가 불필요해지는가?** 를 검사한다.
IFR이 발명의 신규성 앵커(배제 문언, "X의 삭제"형 진보성 논거)가 배제한 요소를 재도입하면
그 IFR은 (a) 진보성 논거를 자기잠식하고 (b) 결합 용이성 공격에 가장 취약한 항이 된다.
실사례: "가변초점 광학"이 가능하면 무광학계 Maxwellian이 불필요 → 해당 청구항을 이산 상태
선택(수동 각인 + 전자 스위칭)으로 재구성.

## P10. 부정 결과 자산화

기각된 해법(과 기각 근거의 정량 논거)을 "반대심문 기록"으로 보존한다. 용도: ① 명세서의
종래기술 결손 논거 ② 회피설계 차단(그 길이 막혀 있음을 교시) ③ 후속 세션의 중복 탐색 방지.
기각 기록에는 반드시 기각을 만든 수치를 남긴다.

## Phase 2 적용 절차 (오케스트레이터·에이전트 공용)

1. 핵심 모순(purpose_relation=핵심) 각각에 P1(3렌즈) 수행 → PC의 단일 파라미터와 요구비 확정.
2. P2 불변량 검사 → 확인 시 P3 공리 분해표 작성(A/B 계열 구분) + P4 심층 구조 1개 이상 탐색.
3. IFR 생성 시 공리 부정별로 배치하고, P3 완결 조합 규칙으로 세트를 검증.
4. 갭이 수치화되면 P5 배율 회계 표 작성.
5. 전 IFR에 P9 자기모순 감사 1줄 기재. 기각분은 P10 형식으로 보존.
6. `triz_analysis.json`의 각 정량 한계 항목에 P6 근사 계층 태그(`approx_level`:
   `geo|gaussian|wave|measured`)와 잠정 여부(`provisional`: true/false)를 기재한다.
   `provisional: true`인 한계는 Phase 6(발명내용설명서)의 정량 문안에서 제외하거나
   검증 필요 사항(§9)으로만 기재한다.
7. 잠정 한계가 발명의 핵심 우위 논거이면 Phase 6 진입 전 P7 사전 등록 검증을 제안한다.
