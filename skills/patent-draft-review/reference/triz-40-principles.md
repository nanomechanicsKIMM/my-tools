# TRIZ 40가지 발명원리

## 1. 분할 (Segmentation)
- 물체를 독립적인 부분으로 나눈다
- 물체를 분리하기 쉽게 만든다
- 물체의 분할 정도를 높인다
- **하위원리**: 1a 독립 부분 분할, 1b 조립식 설계, 1c 분할도 증가

## 2. 추출 (Taking out / Extraction)
- 물체에서 방해가 되는 부분이나 성질을 분리한다
- 필요한 부분이나 성질만 추출한다
- **하위원리**: 2a 불필요 부분 제거, 2b 필요 부분/성질 추출

## 3. 국소적 품질 (Local quality)
- 물체나 환경의 균일한 구조를 불균일하게 변경한다
- 물체의 각 부분이 서로 다른 기능을 수행하도록 한다
- 물체의 각 부분을 최적 조건에 놓는다
- **하위원리**: 3a 균일→불균일, 3b 부분별 기능 차별화, 3c 부분별 최적 조건

## 4. 비대칭 (Asymmetry)
- 대칭인 형태를 비대칭으로 변경한다
- 이미 비대칭이면 비대칭 정도를 높인다
- **하위원리**: 4a 대칭→비대칭, 4b 비대칭도 증가

## 5. 통합 (Merging / Consolidation)
- 동일하거나 유사한 물체/작업을 결합한다
- 인접한 작업을 시간적으로 통합한다
- **하위원리**: 5a 동종 통합, 5b 작업 시간 통합

## 6. 범용성 (Universality)
- 하나의 물체가 여러 기능을 수행하도록 하여 다른 물체를 불필요하게 만든다
- **하위원리**: 6a 다기능화

## 7. 포개기 (Nested doll / Nesting)
- 하나의 물체를 다른 물체 안에 넣는다
- 한 물체가 다른 물체의 빈 공간을 통과하도록 한다
- **하위원리**: 7a 물체 내 배치, 7b 빈 공간 통과, 7c 다단계 포개기

## 8. 평형추 (Anti-weight / Counterweight)
- 물체의 무게를 다른 물체와 결합하여 보상한다
- 환경과의 상호작용(양력, 부력 등)으로 무게를 보상한다
- **하위원리**: 8a 다른 물체로 보상, 8b 환경 상호작용 보상

## 9. 선행 반대 작용 (Preliminary anti-action)
- 해로운 작용이 예상되면 미리 반대 작용을 가한다
- 물체에 미리 응력을 가하여 작업 시 반대 응력을 보상한다
- **하위원리**: 9a 사전 반대 작용, 9b 사전 응력 부여

## 10. 선행 작용 (Preliminary action)
- 필요한 작용을 미리 수행한다 (전부 또는 부분적으로)
- 물체를 미리 배치하여 즉시 사용할 수 있도록 한다
- **하위원리**: 10a 사전 작용, 10b 사전 배치

## 11. 사전 보호 (Beforehand cushioning)
- 물체의 낮은 신뢰성을 미리 준비된 비상수단으로 보상한다
- **하위원리**: 11a 비상수단 준비

## 12. 높이 맞추기 (Equipotentiality)
- 물체를 들어올리거나 내릴 필요가 없도록 작업 조건을 변경한다
- **하위원리**: 12a 위치 에너지 변화 최소화

## 13. 반대로 하기 (The other way round / Inversion)
- 문제를 해결하기 위해 반대 작용을 적용한다
- 움직이는 부분을 고정하고 고정된 부분을 움직이게 한다
- 물체를 뒤집는다
- **하위원리**: 13a 역전 작용, 13b 고정↔이동 반전, 13c 뒤집기

## 14. 곡면화 (Spheroidality / Curvature)
- 직선 형태를 곡선으로, 평면을 곡면으로, 정육면체를 구로 변경한다
- 롤러, 볼, 나선을 사용한다
- 직선운동을 회전운동으로 변경한다
- **하위원리**: 14a 직선→곡선, 14b 회전 요소 사용, 14c 직선→회전 운동

## 15. 역동성 (Dynamics)
- 물체나 환경의 특성이 각 작업 단계에서 최적이 되도록 변경한다
- 물체를 상호 이동 가능한 부분으로 나눈다
- 고정된 물체를 이동 가능하게 만든다
- **하위원리**: 15a 단계별 최적화, 15b 이동 부분 분할, 15c 고정→이동

## 16. 과부족 조치 (Partial or excessive actions)
- 원하는 효과를 100% 달성하기 어려우면 약간 부족하거나 과도하게 수행한다
- **하위원리**: 16a 과부족 작용

## 17. 차원 변경 (Another dimension)
- 1차원 이동을 2차원으로, 2차원을 3차원으로 변경한다
- 다층 구조를 사용한다
- 물체를 기울이거나 옆으로 놓는다
- 주어진 표면의 반대쪽을 이용한다
- **하위원리**: 17a 차원 증가, 17b 다층화, 17c 기울이기, 17d 반대면 활용

## 18. 기계적 진동 (Mechanical vibration)
- 물체를 진동시킨다
- 진동 주파수를 공진 주파수까지 높인다
- 초음파 진동을 이용한다
- 기계적 진동 대신 압전 진동자를 사용한다
- **하위원리**: 18a 진동 적용, 18b 공진, 18c 초음파, 18d 압전

## 19. 주기적 작용 (Periodic action)
- 연속 작용을 주기적(펄스) 작용으로 변경한다
- 이미 주기적이면 주파수를 변경한다
- 펄스 사이의 간격을 활용한다
- **하위원리**: 19a 연속→주기, 19b 주파수 변경, 19c 간격 활용

## 20. 유용한 작용의 연속 (Continuity of useful action)
- 물체의 모든 부분이 항상 최대 부하로 작동하도록 한다
- 공회전과 중간 동작을 제거한다
- 왕복운동을 회전운동으로 변경한다
- **하위원리**: 20a 연속 작동, 20b 공회전 제거, 20c 왕복→회전

## 21. 고속 처리 (Skipping / Rushing through)
- 해로운 공정을 고속으로 수행한다
- **하위원리**: 21a 유해 공정 고속 통과

## 22. 전화위복 (Blessing in disguise / Convert harm into benefit)
- 해로운 요소를 긍정적 효과를 얻는 데 이용한다
- 다른 해로운 요소를 추가하여 해로운 요소를 제거한다
- 해로운 요소가 더 이상 해롭지 않을 정도로 증가시킨다
- **하위원리**: 22a 해로움→유익, 22b 해로움+해로움=유익, 22c 해로움 극대화

## 23. 피드백 (Feedback)
- 피드백을 도입한다
- 이미 피드백이 있으면 변경한다
- **하위원리**: 23a 피드백 도입, 23b 피드백 변경

## 24. 매개체 (Intermediary / Mediator)
- 중간 매개 물체를 사용하여 작용을 전달한다
- 쉽게 제거할 수 있는 물체를 임시로 결합한다
- **하위원리**: 24a 매개체 사용, 24b 임시 결합

## 25. 셀프서비스 (Self-service)
- 물체가 보조 기능과 수리를 스스로 수행하도록 한다
- 폐자원, 에너지, 물질을 활용한다
- **하위원리**: 25a 자가 서비스, 25b 폐자원 활용

## 26. 복사 (Copying)
- 비싸고 깨지기 쉬운 원본 대신 간단하고 저렴한 복사물을 사용한다
- 가시광선 복사 대신 적외선이나 자외선 복사를 사용한다
- **하위원리**: 26a 복사물 대체, 26b 광학적 복사, 26c 다른 파장 활용

## 27. 값싼 일회용품 (Cheap short-living objects)
- 비싸고 내구성 있는 물체를 값싼 일회용 물체로 대체한다
- **하위원리**: 27a 일회용 대체

## 28. 기계 시스템 대체 (Mechanics substitution)
- 기계적 시스템을 광학, 음향, 열, 후각 시스템으로 대체한다
- 전기장, 자기장, 전자기장을 사용한다
- 정적 장을 동적 장으로, 고정 장을 시간에 따라 변하는 장으로 변경한다
- 강자성 입자와 함께 장을 사용한다
- **하위원리**: 28a 장(field) 대체, 28b 전자기장 사용, 28c 정적→동적 장, 28d 강자성 활용

## 29. 공기·유압 (Pneumatics and hydraulics)
- 고체 부분을 기체나 액체로 대체한다 (팽창성, 유체충전, 에어쿠션 등)
- **하위원리**: 29a 고체→기체/액체

## 30. 유연한 막·필름 (Flexible shells and thin films)
- 일반적인 구조 대신 유연한 막이나 필름을 사용한다
- 유연한 막이나 필름으로 물체를 외부 환경과 격리한다
- **하위원리**: 30a 유연 막/필름 사용, 30b 환경 격리

## 31. 다공질 소재 (Porous materials)
- 물체를 다공질로 만들거나 다공질 요소를 추가한다
- 이미 다공질이면 공극에 물질을 채운다
- **하위원리**: 31a 다공질화, 31b 공극 충전

## 32. 색상 변경 (Color changes)
- 물체나 환경의 색상을 변경한다
- 물체나 환경의 투명도를 변경한다
- 보기 어려운 물체를 관찰하기 위해 착색 첨가제를 사용한다
- 이미 사용 중이면 발광 표지나 원자 표지를 사용한다
- **하위원리**: 32a 색상 변경, 32b 투명도 변경, 32c 착색 첨가제, 32d 발광 표지

## 33. 동질성 (Homogeneity)
- 주 물체와 상호작용하는 물체를 같은 재료(또는 유사한 성질)로 만든다
- **하위원리**: 33a 동질 재료

## 34. 폐기·재생 (Discarding and recovering)
- 기능을 완료한 물체의 부분을 폐기(용해, 증발 등)하거나 작업 중 변형시킨다
- 소모된 부분을 작업 중 복원한다
- **하위원리**: 34a 폐기/용해, 34b 작업 중 복원

## 35. 속성 변환 (Parameter changes)
- 물체의 물리적 상태를 변경한다 (기체→액체→고체)
- 농도나 밀도를 변경한다
- 유연성 정도를 변경한다
- 온도나 부피를 변경한다
- **하위원리**: 35a 상태 변경, 35b 농도/밀도 변경, 35c 유연성 변경, 35d 온도/부피 변경

## 36. 상전이 (Phase transitions)
- 상전이 중에 발생하는 현상(부피 변화, 열 방출/흡수 등)을 이용한다
- **하위원리**: 36a 상전이 활용

## 37. 열팽창 (Thermal expansion)
- 재료의 열팽창(수축)을 이용한다
- 열팽창 계수가 다른 여러 재료를 사용한다
- **하위원리**: 37a 열팽창 이용, 37b 이종 재료 열팽창

## 38. 산화 촉진 (Strong oxidants)
- 산소 농축 공기로 일반 공기를 대체한다
- 산소 농축 공기를 순수 산소로 대체한다
- 전리 방사선으로 공기나 산소를 처리한다
- 오존화된 산소를 사용한다
- 오존으로 대체한다
- **하위원리**: 38a 산화제 강화 단계

## 39. 불활성 환경 (Inert atmosphere)
- 일반 환경을 불활성 환경으로 변경한다
- 진공 중에서 공정을 수행한다
- **하위원리**: 39a 불활성 환경, 39b 진공

## 40. 복합 재료 (Composite materials)
- 균질 재료를 복합 재료로 대체한다
- **하위원리**: 40a 복합 재료 대체
