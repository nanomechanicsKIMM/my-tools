# 한국 특허 청구항 형식 규칙 DB

> [!info] 본 문서의 용도
> `patent-draft-review` 스킬의 `claim_parser.py`와 `phase3-claim-structure.md` 에이전트가 참조하는 한국 특허 청구항 형식 규칙과 매몰 차별 요소 판정 기준을 정의한다.

## 1. 청구항 구조 기본 형식

### 1.1 독립 청구항 (Independent Claim)

**표준 구조**:
```
【청구항 1】
[전문부(Preamble)],
[구성요소 1];
[구성요소 2]; 및
[구성요소 N]을 포함하는 [카테고리].
```

**P26057KR1 예시**:
```
【청구항 1】
적어도 하나 이상의 초음파 프로브;
상기 초음파 프로브를 구동하여, 대상체와 초음파를 송수신하는 송수신부;
수신된 초음파로부터 반사행렬을 획득하는 행렬 생성부;
...
상기 위상차를 이용하여 상기 이미지 기반 행렬을 보정하여, 복원 영상을
생성하는 영상 복원부를 포함하는 초음파 영상 시스템.
```

### 1.2 종속 청구항 (Dependent Claim)

**표준 구조**:
```
【청구항 N】
제 M 항에 있어서, 상기 [구성요소]는,
[한정 특징]인 것을 특징으로 하는 [카테고리].
```

**P26057KR1 예시**:
```
【청구항 2】
제1항에 있어서, 상기 대상체는,
상기 초음파를 왜곡하는 장벽을 포함하는 것을 특징으로 하는 초음파 영상 시스템.
```

## 2. 형식 규칙

### 2.1 전문부(Preamble)

| 규칙 | 내용 |
|------|------|
| 목적 | 발명의 카테고리 명시 (시스템/방법/물건/용도) |
| 권장 여부 | **권장** — 심사관이 발명 영역을 즉시 파악 가능 |
| 예시 | "대상체의 장벽을 투과한 초음파 영상의 왜곡을 보정하는 초음파 영상 시스템으로서," |
| 탐지 정규식 | `^.{5,200}?(?:으?로서|에\s*있어서)\s*[,.]` |

### 2.2 "것을 특징으로 하는" 표현

| 규칙 | 내용 |
|------|------|
| 위치 | 종속 청구항 말미 (독립항에도 사용 가능) |
| 목적 | 해당 청구항이 청구하는 특징을 명시 |
| 필수 여부 | 한국 특허 실무 관례상 **준필수** |
| 탐지 정규식 | `것을\s*특징으로\s*하는` |

### 2.3 종속 표현 "제 N 항에 있어서"

| 규칙 | 내용 |
|------|------|
| 위치 | 종속 청구항 첫 문장 |
| 형식 | "제N항에 있어서" 또는 "제 N 항에 있어서" (공백 허용) |
| 다중 종속 | "제1항 내지 제3항 중 어느 한 항에 있어서" (한국 실무상 일부 허용, 일부 제한) |
| 탐지 정규식 | `제\s*(\d+)\s*항\s*에\s*있어서` |

### 2.4 구성요소 구분자

| 구분자 | 용도 |
|--------|------|
| `;` (세미콜론) | 구성요소 간 구분 |
| `및` | 마지막 구성요소 앞에 삽입 |
| `.` (마침표) | 청구항 종료 |

### 2.5 카테고리별 말미 표현

| 카테고리 | 말미 표현 | 탐지 정규식 |
|----------|-----------|-------------|
| 시스템 | 시스템 / 장치 / 디바이스 / 기기 / 회로 / 기판 | `(시스템|장치|디바이스|기기|회로|기판)\s*\.?\s*$` |
| 방법 | 방법 / 공정 / 프로세스 / 복원방법 | `(방법|공정|프로세스|복원방법)\s*\.?\s*$` |
| 물건 | 조성물 / 화합물 / 소재 / 재료 / 물품 | `(조성물|화합물|소재|재료|물품|제품)\s*\.?\s*$` |
| 용도 | 용도 / 사용 방법 | `(용도|사용\s*방법)\s*\.?\s*$` |

## 3. 매몰 차별 요소 (Hidden Distinguishing Element) 탐지

> [!important] 정의
> "매몰 차별 요소"란 명세서 §발명의 효과 섹션에서 강조되었으나 **종속 청구항에만** 존재하는 기술 구성요소를 의미한다. 이러한 요소는 독립항에 승격되면 진보성 방어력이 크게 향상되지만, 종속항에 머물러 있을 경우 심사관 지적이나 선행특허 저촉 시 취약해진다.

### 3.1 판정 기준 (4개 중 **둘 이상** 충족)

| 기준 | 설명 | 구현 방법 |
|------|------|-----------|
| **K1 강조 부사** | §발명의 효과 섹션에서 "특히", "나아가", "무엇보다", "바람직하게는" 등 강조 부사로 수식됨 | 정규식: `(?:특히|나아가|무엇보다|바람직하게는|더욱이)` |
| **K2 단독 단락** | §발명의 효과 섹션에서 해당 요소가 단독 문단으로 2문장 이상 기술됨 | 문단 단위 분리 후 키워드 포함 문단의 문장 수 카운트 |
| **K3 과제 대응** | §해결과제 섹션의 핵심 문제와 1:1로 대응됨 | 과제 키워드와 효과 키워드의 공통 부분집합 |
| **K4 정량 지표** | 수치, 비율, 범위 등 정량 지표로 효과가 표현됨 | 정규식: `\d+(?:\.\d+)?\s*(?:%|배|dB|초|ms|nm|μm|mm|Hz|MHz)` |

### 3.2 매몰 요소 판정 알고리즘

```
FOR each 종속 청구항 C:
    요소들 = extract_distinguishing_elements(C)
    FOR each 요소 E:
        점수 = 0
        IF K1_강조부사(E, §발명의 효과): 점수 += 1
        IF K2_단독단락(E, §발명의 효과): 점수 += 1
        IF K3_과제대응(E, §해결과제, §발명의 효과): 점수 += 1
        IF K4_정량지표(E, §발명의 효과): 점수 += 1
        IF 점수 >= 2:
            MARK C.요소 E AS hidden_distinguishing
```

### 3.3 독립항 승격 권고 기준

- `hidden_distinguishing` 요소가 있는 종속 청구항 → **독립항 승격 후보**
- 단, 승격 시 **권리범위 축소 효과**도 함께 안내 (보정안 비교표에 표시)

### 3.4 P26057KR1 베이스라인 사례

| 청구항 | 요소 | 판정 |
|--------|------|------|
| 제15항 | 송신/수신 수차의 **독립 반복 보정** | K1(특히) + K3(송·수신 수차 혼합 추정 과제 대응) + K4(반복 수렴) → 점수 3, **매몰 차별 요소** |
| 제17항 | **Unwrapping 누적 지연 DAS 반영** | K1(특히) + K3(강한 두개골 수차 환경 과제 대응) → 점수 2, **매몰 차별 요소** |

## 4. 청구항 형식 오류 체크리스트

### 4.1 치명 오류

| ID | 오류 | 수정 |
|----|------|------|
| C-FORM-01 | 청구항에 "것을 특징으로 하는" 누락 | "것을 특징으로 하는 [카테고리]" 추가 |
| C-FORM-02 | 종속 청구항에 "제N항에 있어서" 누락 | "제N항에 있어서, " 문두 추가 |
| C-FORM-03 | 독립항에 전문부 부재 | "[발명 카테고리 설명]으로서," 삽입 |
| C-FORM-04 | 청구항 말미 카테고리 불명확 | 시스템/방법/물건/용도 중 하나로 명확화 |
| C-FORM-05 | 순환 종속 (제N항이 자기 자신을 참조) | 종속 관계 재설계 |
| C-FORM-06 | 존재하지 않는 청구항 번호 참조 | dependent_of 값 수정 |

### 4.2 경미 경고

| ID | 오류 | 개선 |
|----|------|------|
| C-WARN-01 | 구성요소 세미콜론 대신 마침표 사용 | 세미콜론으로 통일 |
| C-WARN-02 | 전문부 지나치게 긴 경우 (200자 초과) | 핵심 카테고리만 남기고 축약 |
| C-WARN-03 | 다중 종속항 "제N항 내지 제M항" 사용 | KR 실무상 가능하나 US 출원 시 문제 — 병렬 종속 권장 |
| C-WARN-04 | 청구항 길이 불균형 (독립항 < 50 chars or > 2000 chars) | 적정 범위로 조정 |

## 5. 청구항 품질 지표

| 지표 | 계산 방식 | 권장 범위 |
|------|-----------|-----------|
| 독립항 개수 | `independent_count` | **2~4개** (시스템+방법, 또는 시스템+방법+물건) |
| 청구항 총 개수 | `total_claims` | **10~30개** (한국 출원) |
| 종속 깊이 | `max_depth` | **1~3** (지나치게 깊으면 회피 용이) |
| 매몰 차별 요소 개수 | `hidden_distinguishing_count` | **0 권장** (모두 독립항으로 승격된 상태) |
| 카테고리 다양성 | `system_count + method_count` | 일반적으로 두 카테고리 병행 권장 |

## 6. 독립항 승격 보정 패턴

### 6.1 보정 타입 A — 기존 독립항에 한정 추가

기존 독립항 문언에 종속항 특징을 삽입.

**예시**: 제1항 + 제15항(Tx/Rx 독립) 병합

```
상기 이미지 기반 행렬에 포함된 기저 이미지와 참조 이미지 사이의 상관성으로부터,
상기 송신기저에 대한 위상차와 상기 수신기저에 대한 위상차를 독립적으로 연산하는
수차 연산부;
```

### 6.2 보정 타입 B — 신규 독립항 추가

새로운 독립항을 별도로 청구.

```
【청구항 N+1】(신규 독립항)
[종속 특징을 주요 구성요소로 하는 새 독립항]
```

### 6.3 보정 타입 C — 2개 청구항을 1개로 통합

종속 청구항 2개를 합쳐 독립항 후보로.

### 6.4 보정 타입 D — 방법항 독립항 분리

시스템 독립항에 종속되던 방법 특징을 별도 방법 독립항으로.
