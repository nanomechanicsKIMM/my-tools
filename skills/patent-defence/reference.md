# Patent Defence — 분석 프레임워크

## 1. 문서 파싱 체크리스트

### 의견제출통지서
- [ ] 심사관 소속팀 (예: "반도체조립공정심사팀")
- [ ] 거절 법조항 (예: 특허법 제29조제2항)
- [ ] 거절 대상 청구항 목록
- [ ] 인용발명 목록 (번호, 공보번호/문헌명, 공개일)
- [ ] 청구항별 거절 논리 (어떤 인용발명 조합이 적용되었는지)

### 명세서
- [ ] 기술분야 (【기술분야】 섹션)
- [ ] 청구항 전문 — 독립항/종속항 구분, 인용 관계 매핑
- [ ] 발명의 효과 (【발명의 내용】→ 효과)
- [ ] 핵심 구성요소 (도면부호 포함)
- [ ] 청구항에 미반영된 명세서 특징 (실시예 중 미활용 구성)

### 당소의견안
- [ ] 보정안 청구항 (보정 텍스트, 삭제 여부)
- [ ] 의견서 논증 구조 (심사관 주장 요약 → 인용발명 분석 → 구성상 특징 → 현저한 효과 → 소결)
- [ ] 대응 범위 (어떤 청구항/인용발명에 대해 대응하고 있는지)
- [ ] 변리사 정보 (이름, 사무소, 사건번호)

## 2. 보정안 권리범위 검토 체크리스트

### 과도한 한정 식별
- [ ] **메커니즘 상위 개념화**: 접속/결합/고정/분리 등의 구체적 방식(용융, 경화, 압착 등)이 명세서의 다른 실시예(ACF, ACP, 열압착 등)를 배제하지 않는지
- [ ] **공정 단계 최소 한정**: 복수 공정 단계(피킹+전사, 코팅+건조+경화 등)를 모두 한정하면 일부만 사용하는 경쟁 제품이 비침해 → 진보성 극복에 필수인 단계만 한정
- [ ] **이동/배치 방식**: 특정 이동 방식(왕복, 회전, 직선)으로 한정하면 다른 실시예(롤투롤, 연속 이송 등)가 배제됨
- [ ] **수치/재료 한정**: 특정 수치 범위나 재료가 불필요하게 좁은 범위로 한정되지 않는지
- [ ] **특정 실시예 종속**: 청구항이 특정 실시예(제1 실시예)에만 해당하고 다른 실시예(제2, 제3 실시예)를 포괄하지 못하는지

### 신규사항 추가 금지
- [ ] 보정 청구항에 추가된 모든 한정에 대해 명세서 근거(line 번호) 확인
- [ ] 명세서에 명시적으로 기재된 내용만 보정에 포함되었는지

## 3. 의견서 논증 완성도 체크리스트

### 거절이유 대응 완전성
- [ ] 심사관 거절이유 전체가 의견서에 요약되었는지 (독립항 거절이유 포함)
- [ ] 모든 인용발명에 대한 차이점 분석이 있는지 (종속항용 인용발명 포함)
- [ ] 보정 청구항의 신규 구성과 의견서 논증이 정합하는지

### 미활용 논거 탐색
- [ ] 명세서에 기재되어 있으나 의견서에서 활용하지 않은 **구조적 차이** 식별
- [ ] 명세서에 기재되어 있으나 의견서에서 활용하지 않은 **현저한 효과** 식별
- [ ] 보정 청구항에 반영된 구성 중 의견서에서 언급하지 않은 항목 식별

### 논증 구조
- [ ] 심사관 주장 요약 → 인용발명 분석 → 구성 차이 → 현저한 효과 → 소결 순서 유지
- [ ] 각 논증에 명세서 근거(line/단락) 명시

## 4. 우선순위 분류 기준

| 우선순위 | 기준 | 예시 |
|---------|------|------|
| **핵심** | 보정안과 의견서의 불일치, 형식 흠결 등 대응 실패 가능성 | 보정 청구항 텍스트가 의견서 논증과 다른 구성을 기재 |
| **필수** | 권리범위에 직접 영향 (과도한 한정, 상위 개념화) | 불필요하게 좁은 메커니즘/공정/이동 방식 한정 |
| **강력 권고** | 설득력 강화 (미활용 효과, 미활용 구조적 차이) | 명세서에 기재된 3건의 효과가 의견서에 미반영 |
| **권고** | 논증 완성도 보강 | 거절이유 요약 누락, 일부 인용발명 미분석 |
| **선택** | 대안적 전략 | 제2 독립항, 도면 대비표, 관련 출원 정합성 |
