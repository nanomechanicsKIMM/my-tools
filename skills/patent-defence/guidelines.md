# Patent Defence Guidelines

> 자동 누적되는 분석 지침. 각 항목은 기술분야에 무관하게 적용 가능.

## 보정안 검증
- [2026-03-24] 보정안 청구항 텍스트와 의견서 논증의 정합성을 반드시 검증
- [2026-03-24] 삭제 청구항은 "삭제" 명시 여부 확인
- [2026-03-24] 보정 청구항에 추가된 모든 한정의 명세서 근거(line 번호)를 확인하여 신규사항 추가 금지 위반 여부 검증
- [2026-03-25] 종속항 삭제 시 해당 종속항을 인용하던 다른 종속항의 인용관계 변경이 정확한지 확인
- [2026-03-25] 의견서 내 불리한 자체 판단 표현("설득이 용이하지 않다", "추가 거절을 주장할 가능성이 있습니다" 등)이 최종 제출본에 포함되지 않는지 확인
- [2026-03-25] 거절이유가 복수 법조항(예: 29조2항 + 42조4항2호)인 경우, 의견서가 모든 거절이유에 대해 대응하고 있는지 확인. 일부 거절이유(특히 기재불비) 대응이 누락되기 쉬움.
- [2026-03-25] 보정 청구항 전문부(preamble)에 핵심 한정을 배치한 경우, 전문부의 한정력 약화 가능성 확인. 핵심 차별화 구성은 청구항 본문(body)에 배치하는 것이 안전.

## 권리범위 검토
- [2026-03-24] 접속/결합/고정 등 메커니즘 표현의 상위 개념화 가능성 검토
- [2026-03-24] 복수 공정 단계를 모두 한정하면 일부만 사용하는 경쟁 제품이 비침해 → 최소 한정 원칙
- [2026-03-24] 특정 이동 방식(롤러 이송 vs 기판 이송)으로 한정하면 다른 실시예가 배제됨
- [2026-03-24] 특정 실시예에만 해당하는 수치/재료/방식이 청구항에 들어가면 다른 실시예가 비침해
- [2026-03-25] 종속항 구성을 독립항에 과다 포함하면 권리범위가 급격히 좁아짐 → 독립항은 최소 구성, 구체적 동작은 종속항 체계로 유지
- [2026-03-25] 분석 초반에 청구항이 물건(장치)항인지 방법항인지 반드시 구분. 방법항은 모든 단계를 실시해야 침해 성립이므로 단계 수 최소화가 물건항보다 훨씬 중요
- [2026-03-25] 방법항만 있고 장치항/물건항이 없는 경우, 발명 명칭·명세서에 장치/물건이 기재되어 있으면 해당 청구항 추가를 권고 (방법 미실시 시 장치 제조·판매가 비침해)
- [2026-03-25] 보정 시 전문부(preamble)와 본문(body)에 동일 취지의 한정이 중복 기재되면 불필요한 권리범위 축소. 전문부에 이미 기재된 내용은 본문에서 반복하지 않아야 함.

## 의견서 논증
- [2026-03-24] 명세서에 기재된 효과 중 의견서에 미활용된 효과를 반드시 탐색
- [2026-03-24] 구조적 차이(투명 기판, 이중 시스템 등)는 강력한 진보성 근거로 활용 가능
- [2026-03-24] 심사관 거절이유 전체(독립항 포함)가 의견서에 요약되었는지 확인
- [2026-03-24] 심사관이 적용한 인용발명 전체에 대해 차이점 분석이 있는지 확인
- [2026-03-25] "상기"를 삭제하여 기재불비를 해결하는 보정보다, 인용관계(종속 대상)를 해당 구성이 기재된 청구항으로 변경하는 것이 더 명확한 해결 방법.
- [2026-06-15] **의견서가 기댄 차별점이 보정 청구항에 실제 반영됐는지 cross-check 필수.** 의견서가 "본원은 무기소재/직접접촉 등으로 다르다"고 주장해도 그 한정이 보정 독립항에 없으면 "청구되지 않은 특징 주장"(MPEP 2145)으로 배척됨. 차별점은 (a)청구항에 반영하거나 (b)청구항에 이미 있는 구성으로 논거를 재구성
- [2026-06-15] **광 정체성·방향성 등 기본 물성 기재(예: 반사=가시광/투과=적외선)가 청구항·명세서·종래기술과 정합하는지 검수.** 종래기술 설명을 본원 설명으로 오기하는 사례 있음(반사/투과 대상 뒤바뀜) → 청구항-의견서 모순으로 심사관 지적 소지

- [2026-07-06] **OA/FOA 원문 확보 전 분석은 잠정본으로 명시.** 당소의견안 요약에는 거절근거가 누락될 수 있음(실사례: FOA의 제2 §103 근거 Wang+Apfel이 당소의견안에 완전 누락, 제안 보정이 제2근거에 무력). 원문 확보 후 거절근거별(법조항 x 청구항 x 인용문헌 조합) 매트릭스를 만들고, 제안 보정이 모든 근거를 끊는지 교차 검증
- [2026-07-06] **이전 의견서에서 명세서에 없는 용어(예: Fabry-Perot)로 논증하면 심사관이 "미개시 원리" 역공.** 의견서 논증은 명세서 문언(예: multiple reflection effect)만 사용

## 인용발명 분석
- [2026-07-06, 2026-07-08 구체화] **심사관이 특정 한정의 근거로 인용한 도면의 축 범위(파장, 온도 등)와 물리량 종류를 도면 이미지에서 직접 판독하여 확인.** 텍스트 요약이나 추정에 의한 범위 주장 금지(실사례: "0.8-2.0μm 뿐"이라는 분석이 원공보 실측 0.5-3.0μm로 반증되어 핵심 논거 교체). 도면이 커버하는 물리량이 청구항 한정과 다른 종류이면(예: 반사율 데이터를 투과율 한정의 근거로 매핑) 그 자체가 prima facie 거절 불성립 논거. MPEP 2143.03(모든 한정 교시 필요), 내재성 반박은 MPEP 2112 IV(필연성 요건)
- [2026-04-07] 인용발명이 본원과 유사한 기능(예: 계절별 전환)을 가진 경우, 단순 기능 차별화가 아닌 **메커니즘 차이**를 핵심 논거로 삼아야 함. "본원도 X를 한다, 인용도 X를 한다"가 아니라 "본원은 A 방식으로 X를 하고, 인용은 B 방식으로 X를 한다"로 논증
- [2026-04-07] 인용발명 PDF가 이미지 기반일 경우, Google Patents(patents.google.com/patent/{공보번호})에서 WebFetch로 원문 추출이 효과적. 당소의견안의 공보번호를 URL로 변환하여 병렬 fetch
- [2026-04-07] §103 조합 거절 시, 각 인용발명의 기술분야·목적·구조를 개별 분석한 후 "조합하더라도 본원 핵심 구성에 도달할 수 없음" + "조합 동기(motivation to combine) 부재"를 병행 반박
- [2026-06-15] **수식/계수 차별화 논거는 인용문헌 원문 단락을 직접 grep 대조 검증.** "본원 수식엔 계수 X(예: 분모 na)가 있어 다르다"는 주장은, 인용발명이 "(or a multiple thereof)"류 일반화 표현으로 동일 수식을 이미 개시하면 즉시 붕괴. 의견서 인용단락을 그대로 믿지 말 것
- [2026-06-15] **수식 일반화 변수(na 등)가 명세서 실시예에서 특정값(특히 선행기술 값, 예 na=1)만 쓰이면 차별력 없음.** 일반화 변수가 권리범위에 선행기술 케이스를 포함하는지 점검
- [2026-06-15] 인용발명의 특정 수치/설계(예 "1/2파장")가 **전체 적층이 아니라 특정 층(보호층 등)에만 적용**되는 값일 수 있음. 의견서가 이를 일반화 인용하면 심사관 역공 빌미 → 원문에서 적용 범위 정확히 확인
- [2026-06-15] §102 anticipation 반박 시, 인용발명이 여러 동작모드(예 가시광 투과/IR 반사 vs 그 역)를 열거해도 **본원 구성 전부를 담은 단일 실시예가 명시되지 않으면** anticipation 불성립. "단일 실시예 명시 개시 부재"로 한정 표현(내재성 반박 대비)

- [2026-07-06] **당소의견안의 인용문헌 목록이 OA 원문 및 작업 폴더 제공 문헌과 일치하는지 대조.** 폴더에 목록 외 공보 PDF가 있으면 신규 인용문헌일 가능성이 높으므로 정체(발명자, 구조)를 확인하고 보정 차별화 논거를 위협하는지 점검(예: "pure metal" 차별화 중 Ag/유전체 적층 선행문헌 존재)

## Critic 검증 (산출물 제출 전, Step 7.5)
- [2026-07-08] **산출물 확정 전 심사관 페르소나(해당 Art Unit 경력 20년) critic 검증을 별도 pass로 수행.** 산출물의 모든 사실 주장을 원문과 전수 대조. md 변환본이 빈 파일/0자이면 원본 PDF를 pymupdf로 페이지별 PNG 렌더링 후 시각 판독
- [2026-07-08] **소극 논거("데이터 부재")보다 적극 논거("존재하는 데이터가 심사관 매핑을 부정")를 우선.** 부재 주장은 원문 데이터 하나로 붕괴하고 역인용 위험 (실사례: 인용발명의 가시광 반사율 0.6-0.7 실측이 "가시광 투과 필터층" 매핑을 정면 부정 — 부재 주장보다 강력)
- [2026-07-08] **인용문헌 데이터가 역인용될 수 있는 구간을 식별하여 해당 류 주장을 금지 표시** (실사례: Fermi 준위별 가시광 반사율 곡선이 근접 → "특성 유지 부정" 주장 금지, 투과율 부재와 고반사 모순으로만 공격)
- [2026-07-08] 통지서 발송일은 요약이나 대리인 보고가 아니라 **표지 Mail Date에서 확인** (실사례: 1차 OA 발송일 2주 오기)
- [2026-07-08] **기계번역본(MT) 단락 번호는 원문과 어긋날 수 있음.** 심사관이 MT를 인용한 경우 반박도 MT 번호로 하되, MT 실물로 단락 대응을 대조 후 인용
- [2026-07-08] **원문이 작업 폴더에 없는 문헌의 "검증 완료" 주장은 재현 불가 → "재확인 필요"로 강등.** 이전 버전 분석의 검증 기록은 버전 교체 시 소실되므로 검증 근거(원문 파일)를 폴더에 남길 것
- [2026-07-08] 심사관이 통지서에 남긴 주석 도면, 각주 등 부수 기재도 판독 — 심사관의 자기모순(예: 인용발명 동작 원리를 스스로 인정)은 보강 논거가 됨
- [2026-07-08] 판정은 오류(수정 필수)/뉘앙스(과장 완화)/확인(강점 목록화)/보강(신규 논거)으로 분류하고, 반영 후 산출물 버전을 올리며 critic 보고서에 적용 기록을 남김

## 미국(US) 특허 대응
- [2026-07-06] **Final OA(FOA) 대응 시 37 CFR 1.116 entry 리스크를 반드시 평가.** 구성 추가 보정은 새 검색을 요하므로 entry 거부 + Advisory Action 가능성 높음. examiner interview(MPEP 713.09) 선행과 RCE(37 CFR 1.114) 대비 일정/비용을 의견안에 명시. AFCP 2.0은 2024-12-14 종료로 활용 불가
- [2026-07-06] **보정으로 도입하는 수식어("pure" 등)가 명세서 문언에 없으면 신규사항(§132) 리스크.** 명세서 예시 재료 기반 표현("comprising silver (Ag)" 등)으로 대체 검토. 직전 OA에서 신규사항 지적을 받은 건이면 특히 치명적
- [2026-07-06] **In re Best(MPEP 2112.01) 구조동일 추정 거절은 명세서 내 구성 유무 대비 데이터(비교예)가 있는지 우선 확인.** 있으면 37 CFR 1.132 선언서로 반박 제안. 단 MPEP 2145 미청구 특징 논증이 되지 않도록 해당 구성의 청구항 한정(최소한 종속항 병합)과 병행
- [2026-07-06] 심사관이 "원리/효과가 명세서에 미개시"라고 주장하면 명세서 원문을 grep으로 사실 검증(동의 표현 존재 여부, 예: Fabry-Perot 대신 multiple reflection). 용어 논쟁을 피하고 명세서 문언 그대로 논증 구성
- [2026-07-06] **OA의 compact prosecution 구문("so long as ... the limitation will be met")은 심사관의 최광의 해석 선언이자 보정 설계 힌트.** 그 해석으로도 회피 불가능한 재료+메커니즘 결합 한정(예: 전압이 그래핀 Fermi level을 제어하여 NIR 흡수 변조)을 명세서 문언 범위에서 설계
- [2026-07-06] Final OA의 2개월 내 응답 기한(MPEP 706.07(f) advisory 유예)과 3개월 SSP, 6개월 최대기한을 구분하여 의견안에 병기 권고. 대리인의 내부 기한만 있으면 의사결정자가 법정기한을 오해할 수 있음
