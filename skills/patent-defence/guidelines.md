# Patent Defence Guidelines

> 자동 누적되는 분석 지침. 각 항목은 기술분야에 무관하게 적용 가능.

## 보정안 검증
- [2026-03-24] 보정안 청구항 텍스트와 의견서 논증의 정합성을 반드시 검증
- [2026-03-24] 삭제 청구항은 "삭제" 명시 여부 확인
- [2026-03-24] 보정 청구항에 추가된 모든 한정의 명세서 근거(line 번호)를 확인하여 신규사항 추가 금지 위반 여부 검증
- [2026-03-25] 종속항 삭제 시 해당 종속항을 인용하던 다른 종속항의 인용관계 변경이 정확한지 확인
- [2026-03-25] 의견서 내 불리한 자체 판단 표현("설득이 용이하지 않다", "추가 거절을 주장할 가능성이 있습니다" 등)이 최종 제출본에 포함되지 않는지 확인
- [2026-03-25] 거절이유가 복수 법조항(예: 29조2항 + 42조4항2호)인 경우, 의견서가 모든 거절이유에 대해 대응하고 있는지 확인. 일부 거절이유(특히 기재불비) 대응이 누락되기 쉬움.
- [2026-03-25] 보정 청구항 전문부(preamble)에 핵심 한정을 배치한 경우, 전문부의 한정력 약화 가능성 확인. 핵심 차별화 구성은 청구항 본문(body)에 배치하는 것이 안전.

## 권리범위 검토
- [2026-03-24] 접속/결합/고정 등 메커니즘 표현의 상위 개념화 가능성 검토
- [2026-03-24] 복수 공정 단계를 모두 한정하면 일부만 사용하는 경쟁 제품이 비침해 → 최소 한정 원칙
- [2026-03-24] 특정 이동 방식(롤러 이송 vs 기판 이송)으로 한정하면 다른 실시예가 배제됨
- [2026-03-24] 특정 실시예에만 해당하는 수치/재료/방식이 청구항에 들어가면 다른 실시예가 비침해
- [2026-03-25] 종속항 구성을 독립항에 과다 포함하면 권리범위가 급격히 좁아짐 → 독립항은 최소 구성, 구체적 동작은 종속항 체계로 유지
- [2026-03-25] 분석 초반에 청구항이 물건(장치)항인지 방법항인지 반드시 구분. 방법항은 모든 단계를 실시해야 침해 성립이므로 단계 수 최소화가 물건항보다 훨씬 중요
- [2026-03-25] 방법항만 있고 장치항/물건항이 없는 경우, 발명 명칭·명세서에 장치/물건이 기재되어 있으면 해당 청구항 추가를 권고 (방법 미실시 시 장치 제조·판매가 비침해)
- [2026-03-25] 보정 시 전문부(preamble)와 본문(body)에 동일 취지의 한정이 중복 기재되면 불필요한 권리범위 축소. 전문부에 이미 기재된 내용은 본문에서 반복하지 않아야 함.

## 의견서 논증
- [2026-03-24] 명세서에 기재된 효과 중 의견서에 미활용된 효과를 반드시 탐색
- [2026-03-24] 구조적 차이(투명 기판, 이중 시스템 등)는 강력한 진보성 근거로 활용 가능
- [2026-03-24] 심사관 거절이유 전체(독립항 포함)가 의견서에 요약되었는지 확인
- [2026-03-24] 심사관이 적용한 인용발명 전체에 대해 차이점 분석이 있는지 확인
- [2026-03-25] "상기"를 삭제하여 기재불비를 해결하는 보정보다, 인용관계(종속 대상)를 해당 구성이 기재된 청구항으로 변경하는 것이 더 명확한 해결 방법.

## 인용발명 분석
- [2026-04-07] 인용발명이 본원과 유사한 기능(예: 계절별 전환)을 가진 경우, 단순 기능 차별화가 아닌 **메커니즘 차이**를 핵심 논거로 삼아야 함. "본원도 X를 한다, 인용도 X를 한다"가 아니라 "본원은 A 방식으로 X를 하고, 인용은 B 방식으로 X를 한다"로 논증
- [2026-04-07] 인용발명 PDF가 이미지 기반일 경우, Google Patents(patents.google.com/patent/{공보번호})에서 WebFetch로 원문 추출이 효과적. 당소의견안의 공보번호를 URL로 변환하여 병렬 fetch
- [2026-04-07] §103 조합 거절 시, 각 인용발명의 기술분야·목적·구조를 개별 분석한 후 "조합하더라도 본원 핵심 구성에 도달할 수 없음" + "조합 동기(motivation to combine) 부재"를 병행 반박

## 파일 변환
- [2026-04-07] docx 변환 시 python-docx의 `para.text`는 tracked changes(변경 내용)를 누락함. XML 직접 파싱으로 `w:ins`(삽입), `w:del`(삭제)을 `{+...+}`, `{-...-}` 형식으로 추출해야 함
- [2026-04-07] 이미지 기반 PDF(텍스트 0자)는 pymupdf4llm/fitz 모두 추출 불가. Google Patents WebFetch를 우선 시도하고, 그래도 불가 시 당소의견안 내 요약으로 대체

## 산출물 형식
- [2026-04-07] 업데이트내역 말미에 "인용 문서 및 출처" 섹션을 추가하여, 분석에서 인용한 모든 문서의 공보번호/DOI를 표로 정리. 논문의 경우 DOI 검색을 시도하고, 미확인 시 "DOI 미확인"으로 표기

## 미국(US) 특허 대응
- [2026-04-07] US 심사 대응 시 35 USC 기준 법률 용어 사용 필수: §112(a) written description, §112(b) definiteness, §102 novelty, §103 nonobviousness
- [2026-04-07] 기능적 표현(functional claim language) 거절 시, 논문/교과서 인용으로 당업자 자명성(PHOSITA)을 입증하는 전략이 유효. 단, 해당 논문은 IDS로 제출해야 하며 37 CFR 1.56 duty of disclosure 의무 고려
- [2026-04-07] 패밀리 출원(KR/JP/EP) 대응 이력이 있는 경우, 각국 보정 내용과 US 전략의 정합성/차별성을 명시적으로 분석. US에서 더 넓은 권리범위를 추구하는 경우 그 근거를 기재

## 사용자 피드백
- [2026-03-24] 인용발명 결합의 비자명성(hindsight) 논거는 심사관 설득력 부족 → 제외
- [2026-03-24] 종속항별 개별 반박은 독립항 인정 시 자연 해결이므로 불필요
