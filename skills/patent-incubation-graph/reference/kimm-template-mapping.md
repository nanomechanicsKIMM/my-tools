## 치환 전략

### 기본 접근: `zip_replace()` 사용

각 섹션 내용을 치환할 때 `{고유키: 새 내용}` 딕셔너리를 사용한다.

```python
replacements = {
    # §1 발명의 명칭 (단일 텍스트 치환)
    "미소소자의 가변 피치 롤 전사 방법 및 장비": new_title,

    # §2 논문발표 (단일 텍스트 치환)
    "해당 없음.": new_publication_status,

    # §3~§8: 첫 번째 hp:t 텍스트를 새 내용으로 치환
    # §9: XML 이스케이프된 텍스트 사용
    "&lt;기존 기술과 본 발명의 차이&gt;": new_additional_materials,
}
```

### 다중 단락 섹션 치환 전략

§3~§8은 **여러 단락**으로 구성되어 있으므로, 단순 텍스트 치환만으로는 부족하다. 두 가지 전략이 가능하다:

#### 전략 A: 전체 셀 내용 교체 (권장)

셀의 `<hp:tc>` 내부 전체를 교체한다. 첫 단락의 XML 구조를 템플릿으로 사용하고, 나머지 단락은 같은 구조로 복제한다.

```python
# 단일 단락 XML 템플릿 (paraPrIDRef="14", charPrIDRef="11" 기준)
PARA_TEMPLATE = (
    '<hp:p id="0" paraPrIDRef="{paraPrIDRef}" styleIDRef="0" '
    'pageBreak="0" columnBreak="0" merged="0">'
    '<hp:run charPrIDRef="{charPrIDRef}">'
    '<hp:t>{text}</hp:t>'
    '</hp:run>'
    '<hp:linesegarray>'
    '<hp:lineseg textpos="0" vertpos="0" vertsize="1000" '
    'textheight="1000" baseline="850" spacing="600" '
    'horzpos="0" horzsize="41672" flags="2490368"/>'
    '</hp:linesegarray>'
    '</hp:p>'
)
```

#### 전략 B: 첫 번째 텍스트만 교체 (간단한 경우)

§1, §2처럼 단일 단락인 경우, `hp:t` 내의 텍스트만 교체하면 충분하다.

```python
# 단순 텍스트 치환으로 충분한 섹션
SIMPLE_SECTIONS = ["§1", "§2"]

# 전체 셀 교체가 필요한 섹션
COMPLEX_SECTIONS = ["§3", "§4", "§5", "§6", "§7", "§8", "§9"]
```
