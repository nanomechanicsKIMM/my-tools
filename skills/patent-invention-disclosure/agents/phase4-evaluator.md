# Phase 4: 정량 평가 & 순위화

## 입력

1. `invention_manifest.json`의 `input` 필드
2. `triz_analysis.json` (Phase 2 출력, 사용자 검토 후 확정본)
3. `templates/evaluation-matrix.md` (평가 템플릿)

## 작업

### 평가 기준 (4항목, 각 1-10점)

| 기준 | 가중치 | 평가 기준 |
|------|--------|-----------|
| 실현 가능성 (F) | 0.30 | 현재 기술로 구현 가능한 정도 |
| 비용 효율 (C) | 0.20 | 개발·제조 비용 대비 효율 |
| 기술적 효과 (E) | 0.30 | 문제 해결 효과의 크기 |
| 산업적 가치 (V) | 0.20 | 시장성, 특허성, 사업화 가능성 |

### 종합점수 계산

```
종합점수 = F×0.30 + C×0.20 + E×0.30 + V×0.20
```

### 평가 절차

1. 각 IFR에 대해 4항목 점수 부여 (1-10, 정수)
2. 가중평균 종합점수 계산
3. 종합점수 기준 내림차순 정렬
4. 상위 3개 IFR에 대해 강점/약점 코멘트 추가

### 점수 기준 가이드

**실현 가능성**:
- 9-10: 기존 기술/장비로 즉시 구현 가능
- 7-8: 약간의 개발 필요하나 기술적 장벽 낮음
- 5-6: 추가 연구개발 필요
- 3-4: 핵심 기술 미확보, 상당한 개발 필요
- 1-2: 현재 기술로 구현 불가능

**산업적 가치**:
- 9-10: 기존 제품/시장에 즉시 적용 가능, 높은 특허성
- 7-8: 특정 시장에 적용 가능, 특허 가능성 높음
- 5-6: 시장 잠재력 있으나 사업화에 추가 검증 필요
- 3-4: 시장이 제한적이거나 특허성 불확실
- 1-2: 산업적 활용 어려움

## 출력

`evaluation.json` 파일로 저장:

```json
{
  "evaluations": [
    {
      "ifr_id": 1,
      "scores": {
        "feasibility": 8,
        "cost": 7,
        "effect": 9,
        "industrial_value": 8
      },
      "weighted_score": 8.1,
      "comment": "강점/약점 코멘트"
    }
  ],
  "ranking": [
    {"rank": 1, "ifr_id": 3, "score": 8.5, "highlight": "최고 실현가능성+효과"},
    {"rank": 2, "ifr_id": 1, "score": 8.1, "highlight": "균형 잡힌 점수"},
    {"rank": 3, "ifr_id": 7, "score": 7.8, "highlight": "높은 산업가치"}
  ]
}
```

## 주의사항

- 평가는 사용자가 Phase 3에서 검토/수정한 IFR 목록을 기준으로 수행
- Phase 5(선행특허) 결과 반영 전이므로 novelty(신규성)는 평가 항목에 포함하지 않음
- Phase 6(발명내용설명서 작성)에서 선행특허 기반으로 순위를 재조정함
